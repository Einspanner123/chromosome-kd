# Active research notes

This directory is deliberately small. It contains scientific boundaries and
evidence indices, not executable experiment recipes.

- `RESEARCH_SCOPE.md`: Generation–Decision–Deployment scope and claim limits.
- `DEPLOYMENT_FINDINGS.md`: renewal, Top-K, head-distillation, and GACS evidence.
- `notes/dpm_solver_plus_plus_rf_derivation.md`: RF/DPM++ derivation and scope.
- `citation_audit_20260813.md`: reference provenance.

Speculative, superseded, and falsified directions were removed from the active
tree to prevent accidental reuse. They remain recoverable from
`refs/tags/archive/pre-cleanup-20260815` and are summarized by the experiment
database findings rather than maintained as competing design documents.
