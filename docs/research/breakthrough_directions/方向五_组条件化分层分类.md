# 方向五：组条件化分层分类 (Group-Conditioned Hierarchical Classification)

> **目标**：利用染色体 8 组生物学结构（A-G + Sex），将扁平 24 类分类分解为"先组后类"的分层分类，并引入组条件扩散，降低组内混淆（C6-C12、D13-D15 等）。
>
> **理论依据**：
> - Hierarchical Softmax: Morin & Bengio (2005)
> - 信息论分解：$H(Y) = H(G) + H(Y|G)$
> - 条件扩散：class-conditional diffusion (Dhariwal & Nichol, 2021)
>
> **当前代码位置**：[ldmdet/core/single_head.py](../../ldmdet/core/single_head.py), [ldmdet/utils/constants.py](../../ldmdet/utils/constants.py)

---

## 1. 问题分析：扁平分类的局限

### 1.1 染色体混淆模式

染色体 24 类按生物学分为 8 组：

| 组 | 类别 | 数量 | 典型混淆 |
|----|------|------|---------|
| A | 1,2,3 | 3 | 极少混淆（尺寸最大） |
| B | 4,5 | 2 | 极少混淆 |
| C | 6,7,8,9,10,11,12 | 7 | **高混淆**（形态相似） |
| D | 13,14,15 | 3 | **高混淆**（近端着丝粒） |
| E | 16,17,18 | 3 | 中等混淆 |
| F | 19,20 | 2 | 中等混淆 |
| G | 21,22 | 2 | **高混淆**（小尺寸） |
| Sex | X,Y | 2 | 中等混淆 |

**关键观察**：混淆几乎全在组内，组间混淆极少。扁平 24 类分类对所有类一视同仁，未利用此结构。

### 1.2 当前实现

[single_head.py:200](../../ldmdet/core/single_head.py#L200) 的分类头是扁平的：

```python
class_logits = self.cls_head(fc_feature)  # [bs, N, 24]
```

[constants.py:10-20](../../ldmdet/utils/constants.py#L10-L20) 定义了组映射但仅用于 GHSS 耦合：

```python
CHROMO_GROUP_OF_CLASS = [0,0,0, 1,1, 2,2,2,2,2,2,2, 3,3,3, 4,4,4, 5,5, 6,6, 7,7]
```

### 1.3 数学问题

**信息论分析**：

24 类均匀分布的熵：

$$
H(Y) = \log_2 24 \approx 4.58 \text{ bits}
$$

分解为组 + 组内：

$$
H(Y) = H(G) + H(Y|G)
$$

- $H(G) = \log_2 8 = 3$ bits（8 组）
- $H(Y|G) = \sum_g p(g) H(Y|G=g)$

假设组内均匀：

| 组 $g$ | $K_g$ | $H(Y|G=g)$ | $p(g)$ | 贡献 |
|--------|-------|------------|--------|------|
| A | 3 | 1.58 | 3/24 | 0.20 |
| B | 2 | 1.00 | 2/24 | 0.08 |
| C | 7 | 2.81 | 7/24 | 0.82 |
| D | 3 | 1.58 | 3/24 | 0.20 |
| E | 3 | 1.58 | 3/24 | 0.20 |
| F | 2 | 1.00 | 2/24 | 0.08 |
| G | 2 | 1.00 | 2/24 | 0.08 |
| Sex | 2 | 1.00 | 2/24 | 0.08 |

$$
H(Y|G) \approx 1.74 \text{ bits}
$$

**结论**：分层后组内分类熵仅 1.74 bits（vs 扁平 4.58 bits），降低 62%。理论上分层分类的难度显著降低。

## 2. 数学推导

### 2.1 分层 Softmax

#### 2.1.1 概率分解

$$
p(y \mid x) = p(g \mid x) \cdot p(y \mid g, x)
$$

其中 $g = \text{group}(y)$ 是确定映射。

#### 2.1.2 损失函数

$$
\mathcal{L}_{\text{hier}} = \mathcal{L}_{\text{group}} + \lambda \cdot \mathcal{L}_{\text{class|group}}
$$

- $\mathcal{L}_{\text{group}}$：8 组分类的 Focal Loss
- $\mathcal{L}_{\text{class|group}}$：组内分类的 Focal Loss（仅对正确组的 logit 计算）

#### 2.1.3 数值稳定性

直接实现 $p(y) = p(g) \cdot p(y|g)$ 在 log 空间：

$$
\log p(y) = \log p(g) + \log p(y|g)
$$

训练时用 NLL：

$$
\mathcal{L} = -\log p(g^*) - \log p(y^* | g^*)
$$

### 2.2 组条件扩散

#### 2.2.1 条件生成

将组 $g$ 作为条件注入扩散过程：

$$
p_\theta(x_0, y \mid g) = p_\theta(x_0 \mid g) \cdot p_\theta(y \mid x_0, g)
$$

- $p_\theta(x_0 \mid g)$：组条件框生成（同组框形态相似，生成更聚焦）
- $p_\theta(y \mid x_0, g)$：组内分类（仅需区分组内 $K_g$ 类）

#### 2.2.2 AdaLN-Zero 组条件化

扩展 [single_head.py:210](../../ldmdet/core/single_head.py#L210) 的 AdaLN-Zero，将组嵌入注入：

```python
adaln_params = self.adaln_mlp(time_emb + group_emb)
```

组嵌入：

$$
\mathbf{g}_{\text{emb}} = \text{Embed}(g), \quad g \in \{0, ..., 7\}
$$

#### 2.2.3 训练时的组标签

训练时 GT 框的组标签 $g = \text{group}(y)$ 已知（从 `CHROMO_GROUP_OF_CLASS` 查表）。推理时：
1. 先预测组 $g$
2. 用 $g$ 条件化扩散生成
3. 在组内分类

### 2.3 组感知匹配

#### 2.3.1 匹配代价的组结构

当前 [matcher.py](../../ldmdet/criterion/matcher.py) 的 Focal Loss 代价对所有 24 类一视同仁。组感知匹配可对组间错误施加更高惩罚：

$$
\mathcal{C}_{\text{cls}}^{\text{group}}(i, j) = \mathcal{C}_{\text{cls}}(i, j) + \lambda_{\text{cross}} \cdot \mathbb{1}[\text{group}(y_i) \neq \text{group}(y_j)]
$$

但由于匹配是 proposal→GT，GT 的组已知，此惩罚实际作用于**分类头**而非匹配。

#### 2.3.2 组内 Top-K 匹配

更激进：匹配时仅在组内 proposal 中选 Top-K。但这需要 proposal 先有组预测，引入先有鸡还是先有蛋问题。**不推荐**，保持匹配不变，仅改分类。

## 3. 实现方案

### 3.1 分层分类头

新建 [ldmdet/core/hierarchical_head.py](../../ldmdet/core/hierarchical_head.py)：

```python
"""分层分类头: 先组后类"""

import torch
import torch.nn as nn
import torch.nn.functional as F

from ldmdet.utils.constants import CHROMO_GROUP_OF_CLASS, NUM_CHROMO_GROUPS


class HierarchicalClsHead(nn.Module):
    """分层分类头.

    将 24 类分类分解为:
    1. 组分类: 8 组 (A-G + Sex)
    2. 组内分类: 每组 K_g 类

    概率: p(y|x) = p(g|x) * p(y|g,x)

    Args:
        feat_channels: 输入特征维度
        num_classes: 总类别数 (24)
        num_groups: 组数 (8)
        group_of_class: class_idx → group_idx 映射
    """

    def __init__(
        self,
        feat_channels: int = 256,
        num_classes: int = 24,
        num_groups: int = NUM_CHROMO_GROUPS,
        group_of_class: list = CHROMO_GROUP_OF_CLASS,
    ):
        super().__init__()
        self.feat_channels = feat_channels
        self.num_classes = num_classes
        self.num_groups = num_groups

        # 注册组映射为 buffer (不进 state_dict, 避免迁移问题)
        self.register_buffer(
            'group_of_class',
            torch.tensor(group_of_class, dtype=torch.long),
            persistent=False,
        )

        # 组分类头
        self.group_head = nn.Linear(feat_channels, num_groups)

        # 组内分类头: 每组一个独立的线性层
        # 用 ModuleList 存储, 每组输出 K_g 个 logit
        self.class_heads = nn.ModuleList()
        for g in range(num_groups):
            K_g = sum(1 for gc in group_of_class if gc == g)
            self.class_heads.append(nn.Linear(feat_channels, K_g))

        # 预计算每组包含的 class_idx (用于推理时映射回全局类别)
        self.class_indices_per_group = []
        for g in range(num_groups):
            indices = [i for i, gc in enumerate(group_of_class) if gc == g]
            self.class_indices_per_group.append(indices)

    def forward(self, x: torch.Tensor) -> dict:
        """
        Args:
            x: [bs, N, feat_channels] 或 [bs*N, feat_channels]

        Returns:
            dict with:
                group_logits: [bs, N, num_groups]
                class_logits_per_group: list of [bs, N, K_g]
                flat_logits: [bs, N, num_classes] (组合后, 用于兼容)
        """
        original_shape = x.shape
        if x.dim() == 3:
            bs, N, C = x.shape
            x_flat = x.reshape(bs * N, C)
        else:
            x_flat = x

        # 组分类
        group_logits = self.group_head(x_flat)  # [bs*N, num_groups]

        # 组内分类
        class_logits_per_group = []
        for g, head in enumerate(self.class_heads):
            class_logits_per_group.append(head(x_flat))  # [bs*N, K_g]

        # 组合为扁平 logits (用于兼容现有匹配器和损失)
        flat_logits = torch.full(
            (x_flat.shape[0], self.num_classes),
            -10.0,  # 未选中组的类 logit 设为极小
            device=x_flat.device,
            dtype=x_flat.dtype,
        )

        # 用 log-sum-exp 组合: log p(y) = log p(g) + log p(y|g)
        log_p_group = F.log_softmax(group_logits, dim=-1)  # [bs*N, num_groups]
        for g, (cls_lg, indices) in enumerate(
            zip(class_logits_per_group, self.class_indices_per_group)
        ):
            log_p_class_given_group = F.log_softmax(cls_lg, dim=-1)  # [bs*N, K_g]
            log_p_y = log_p_group[:, g:g+1] + log_p_class_given_group  # [bs*N, K_g]
            # scatter 到 flat_logits
            idx_tensor = torch.tensor(
                indices, device=x_flat.device, dtype=torch.long
            )
            flat_logits.scatter_(1, idx_tensor.unsqueeze(0).expand_as(log_p_y), log_p_y)

        # reshape 回原形状
        if len(original_shape) == 3:
            group_logits = group_logits.view(original_shape[0], original_shape[1], -1)
            class_logits_per_group = [
                cl.view(original_shape[0], original_shape[1], -1)
                for cl in class_logits_per_group
            ]
            flat_logits = flat_logits.view(original_shape[0], original_shape[1], -1)

        return {
            'group_logits': group_logits,
            'class_logits_per_group': class_logits_per_group,
            'flat_logits': flat_logits,
        }

    def loss(
        self,
        flat_logits: torch.Tensor,
        group_logits: torch.Tensor,
        class_logits_per_group: list,
        targets: torch.Tensor,  # [bs, N] 全局类别标签
        focal_alpha: float = 0.25,
        focal_gamma: float = 2.0,
        lambda_class: float = 1.0,
    ) -> dict:
        """计算分层分类损失.

        Returns:
            dict with loss_group, loss_class, loss_total
        """
        bs, N = targets.shape[:2]
        device = targets.device

        # 组标签
        group_targets = self.group_of_class.to(device)[targets.clamp(min=0)]  # [bs, N]
        valid_mask = targets >= 0  # 忽略 padding

        # 组分类损失 (Focal Loss)
        loss_group = self._focal_loss(
            group_logits, group_targets, valid_mask,
            focal_alpha, focal_gamma,
        )

        # 组内分类损失 (仅对正确组计算)
        loss_class = torch.tensor(0.0, device=device)
        for g, (cls_lg, indices) in enumerate(
            zip(class_logits_per_group, self.class_indices_per_group)
        ):
            g_mask = (group_targets == g) & valid_mask  # [bs, N]
            if g_mask.sum() == 0:
                continue
            # 该组内的局部类别标签
            idx_map = {global_idx: local_idx for local_idx, global_idx in enumerate(indices)}
            local_targets = torch.zeros_like(targets)
            for gi, global_idx in enumerate(indices):
                local_targets[targets == global_idx] = gi
            local_targets_g = local_targets[g_mask]  # [K]
            cls_lg_g = cls_lg[g_mask]  # [K, K_g]
            loss_class = loss_class + self._focal_loss(
                cls_lg_g.unsqueeze(0), local_targets_g.unsqueeze(0),
                torch.ones_like(local_targets_g, dtype=torch.bool).unsqueeze(0),
                focal_alpha, focal_gamma,
            )

        return {
            'loss_group': loss_group,
            'loss_class': loss_class * lambda_class,
            'loss_total': loss_group + loss_class * lambda_class,
        }

    @staticmethod
    def _focal_loss(logits, targets, mask, alpha, gamma):
        """简化 Focal Loss"""
        ce = F.cross_entropy(logits[mask], targets[mask], reduction='none')
        p = torch.exp(-ce)
        loss = alpha * (1 - p) ** gamma * ce
        return loss.mean()
```

### 3.2 组条件扩散

修改 [single_head.py](../../ldmdet/core/single_head.py)，注入组嵌入：

```python
class GroupConditionedSingleHead(SingleDiffusionDetHead):
    """组条件化 Single Head.

    在 AdaLN-Zero 中注入组嵌入, 使扩散过程组感知.
    """

    def __init__(
        self,
        *args,
        num_groups: int = 8,
        group_emb_dim: int = None,
        **kwargs,
    ):
        super().__init__(*args, **kwargs)
        feat_channels = self.feat_channels
        if group_emb_dim is None:
            group_emb_dim = feat_channels * 4

        # 组嵌入表
        self.group_embedding = nn.Embedding(num_groups, group_emb_dim)

        # 修改 adaln_mlp 输入维度 (time_emb + group_emb)
        # 原: adaln_mlp = Linear(feat_channels*4, feat_channels*4*6)
        # 新: adaln_mlp = Linear(feat_channels*4 + group_emb_dim, feat_channels*4*6)
        # 注意: 需要在父类初始化后替换 adaln_mlp
        old_adaln = self.adaln_mlp
        self.adaln_mlp = nn.Sequential(
            nn.Linear(feat_channels * 4 + group_emb_dim, feat_channels * 4),
            nn.SiLU(),
            nn.Linear(feat_channels * 4, feat_channels * 4 * 6),
        )
        # 初始化最后一层为 zero (AdaLN-Zero)
        nn.init.zeros_(self.adaln_mlp[-1].weight)
        nn.init.zeros_(self.adaln_mlp[-1].bias)

    def _forward_adaln_zero(
        self, proposals, roi_features, time_emb, bs, num_boxes,
        group_labels=None,
    ):
        """组条件化 AdaLN-Zero.

        Args:
            group_labels: [bs, N] 每个框的组标签, 若 None 则用 0 (无条件)
        """
        if group_labels is None:
            group_labels = torch.zeros(
                bs, num_boxes, dtype=torch.long, device=time_emb.device
            )

        # 组嵌入: [bs, N, group_emb_dim]
        group_emb = self.group_embedding(group_labels)
        # 广播 time_emb 到每个框: [bs, 1, feat*4] → [bs, N, feat*4]
        time_emb_expanded = time_emb.unsqueeze(1).expand(-1, num_boxes, -1)
        # 融合: [bs, N, feat*4 + group_emb_dim]
        cond_emb = torch.cat([time_emb_expanded, group_emb], dim=-1)

        # reshape for adaln_mlp
        proposals = proposals.view(bs, num_boxes, self.feat_channels).permute(1, 0, 2)
        cond_flat = cond_emb.reshape(bs * num_boxes, -1)
        adaln_params = self.adaln_mlp(cond_flat)
        adaln_params = adaln_params.view(num_boxes, bs, -1)

        gamma1, beta1, alpha1, gamma2, beta2, alpha2 = adaln_params.chunk(6, dim=-1)

        # ... 后续与父类相同 ...
        proposals_flat = proposals.reshape(num_boxes * bs, self.feat_channels)
        q_modulated = F.layer_norm(proposals_flat, [self.feat_channels]) * (1 + gamma1.reshape(-1, self.feat_channels)) + beta1.reshape(-1, self.feat_channels)
        q_modulated = q_modulated.view(num_boxes, bs, self.feat_channels)
        attn_out, _ = self._self_attn(q_modulated)
        attn_out_flat = attn_out.reshape(num_boxes * bs, self.feat_channels)
        proposals_flat = proposals_flat + alpha1.reshape(-1, self.feat_channels) * attn_out_flat

        proposals = proposals_flat.view(num_boxes, bs, self.feat_channels)
        proposals = proposals.permute(1, 0, 2).reshape(1, bs * num_boxes, self.feat_channels)
        inst_out = self.inst_interact(proposals, roi_features)
        proposals = proposals + self.dropout2(inst_out)
        obj_features = self.norm2(proposals)

        obj_flat = obj_features.squeeze(0)
        ffn_input = F.layer_norm(obj_flat, [self.feat_channels]) * (1 + gamma2.reshape(-1, self.feat_channels)) + beta2.reshape(-1, self.feat_channels)
        ffn_out = self.linear2(self.dropout(self.act(self.linear1(ffn_input))))
        obj_flat = obj_flat + alpha2.reshape(-1, self.feat_channels) * ffn_out
        return obj_flat
```

### 4.4 信息论验证

- $H(Y)$：扁平分类输出的平均熵

## 5. 预期收益与风险

### 收益

1. **组内混淆降低**：C/D/G 组的 per-class AP 预期提升 2-5%
2. **分类置信度提升**：分层后组内决策更聚焦，置信度校准更好
3. **组条件生成**：同组框形态相似，条件化后生成质量提升
4. **信息论优雅**：利用已知的生物学结构，降低分类难度 62%

### 风险

1. **错误传播**：组分类错误时，组内分类无意义（级联错误）
2. **训练复杂度**：分层损失需谨慎平衡 $\lambda_{\text{class}}$
3. **推理开销**：组条件化需先预测组，增加推理步骤
4. **与匹配器的兼容**：扁平 logits 的 log-sum-exp 组合可能影响 Focal Loss 代价计算

### 缓解

1. **级联错误**：组分类用大权重（$\lambda_{\text{group}}=1.0$），确保组分类准确率 > 95%
2. **兼容性**：`flat_logits` 通过 log-sum-exp 组合，保持与现有匹配器/损失兼容
3. **推理**：组预测可与框预测并行，不显著增加延迟
