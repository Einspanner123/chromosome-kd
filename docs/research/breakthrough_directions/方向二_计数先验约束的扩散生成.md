# 方向二：计数先验约束的扩散生成 (Count-Prior Constrained Diffusion)

> **目标**：将核型分析的强计数先验（正常 46 条，异常核型已知总数）注入扩散生成过程，提升检测计数准确性。
>
> **理论依据**：
> - 路径 A：Classifier-free guidance (Ho & Salimans, 2022) + 条件扩散
> - 路径 B：约束生成 (Chung et al., 2022 "Come-Closer-Diffuse-Faster") + 拉格朗日对偶
>
> **当前代码位置**：[ldmdet/core/head.py](../../ldmdet/core/head.py), [ldmdet/core/single_head.py](../../ldmdet/core/single_head.py)

## 1. 问题分析：计数先验未被利用

### 1.1 染色体核型的强先验

核型分析有明确的计数先验：

| 核型 | 染色体总数 | 性染色体 |
|------|-----------|---------|
| 正常男性 (46,XY) | 46 | X, Y |
| 正常女性 (46,XX) | 46 | X, X |
| Turner 综合征 (45,X) | 45 | X |
| Klinefelter (47,XXY) | 47 | X, X, Y |
| Down 综合征 (47,XX,+21) | 47 | — |

**关键观察**：总数 $c$ 几乎总是 $\in \{45, 46, 47\}$，且对每个样本是**已知**的（医学先验或粗计数）。当前模型完全忽略此信息。

## 2. 数学推导

### 2.1 路径 A：计数条件化生成 (Count-Conditioned Diffusion)

#### 2.1.1 条件扩散目标

将计数 $c$ 作为条件注入扩散过程：

$$
p_\theta(x_0 \mid c) = \int p_\theta(x_0 \mid x_t, t, c) \, p(x_t \mid c) \, dx_t
$$

训练目标变为：

$$
\mathcal{L}_{\text{count}} = \mathbb{E}_{x_0, c, t, \epsilon}\left[\|v_\theta(x_t, t, c) - (x_1 - x_0)\|^2\right]
$$

其中 $v_\theta$ 现在接受 $c$ 作为额外输入。

#### 2.1.2 计数编码

将 $c$ 编码为向量，与时间嵌入融合。设 $c \in \{44, ..., 48\}$（覆盖常见核型），编码方式：

**方案 1：标量嵌入**

$$
\mathbf{c}_{\text{emb}} = \text{MLP}(\text{SinusoidalEmbed}(c))
$$

与 `time_emb` 维度相同（`feat_channels * 4`），通过相加融合：

$$
\mathbf{e} = \text{time\_mlp}(t) + \text{count\_mlp}(c)
$$

**方案 2：Classifier-Free Guidance (CFG)**

训练时以概率 $p_{\text{drop}}$ 丢弃条件（$c \to \emptyset$），推理时用 CFG：

$$
\tilde{v}_\theta(x_t, t, c) = (1 + w) \cdot v_\theta(x_t, t, c) - w \cdot v_\theta(x_t, t, \emptyset)
$$

其中 $w$ 为引导强度。$w=0$ 退化为纯条件生成，$w$ 越大计数约束越强。

#### 2.1.3 AdaLN-Zero 扩展

当前 [single_head.py:210](../../ldmdet/core/single_head.py#L210)：

```python
adaln_params = self.adaln_mlp(time_emb)  # → 6 * feat_channels
```

扩展为接受融合嵌入 $\mathbf{e}$：

```python
adaln_params = self.adaln_mlp(time_emb + count_emb)
```

**数学等价性**：AdaLN-Zero 的调制参数 $(\gamma, \beta, \alpha)$ 现在是 $(t, c)$ 的函数，使归一化的均值/方差随计数调整。直觉上：$c=47$ 时模型应"放宽"置信度阈值以多保留一个 proposal。

### 2.2 路径 B：拉格朗日约束推理 (Lagrangian Constrained Inference)

#### 2.2.1 约束优化形式

推理时，将检测视为带约束的优化：

$$
\min_{\tau} \mathcal{L}_{\text{det}}(\tau) \quad \text{s.t.} \quad \sum_i \mathbb{1}[\text{conf}_i > \tau] = c
$$

其中 $\tau$ 是置信度阈值，$\mathcal{L}_{\text{det}}$ 是检测损失（此处简化为负检测分数和）。

#### 2.2.2 拉格朗日对偶

引入拉格朗日乘子 $\mu$：

$$
\mathcal{L}(\tau, \mu) = \mathcal{L}_{\text{det}}(\tau) + \mu \left(\sum_i \mathbb{1}[\text{conf}_i > \tau] - c\right)
$$

对偶问题：

$$
\max_\mu \min_\tau \mathcal{L}(\tau, \mu)
$$

#### 2.2.3 对偶上升算法

由于 $\mathbb{1}[\cdot]$ 不可微，用软阈值替代：

$$
\sigma_\beta(\text{conf}_i - \tau) = \frac{1}{1 + e^{-\beta(\text{conf}_i - \tau)}}
$$

$\beta \to \infty$ 时退化为硬阈值。对偶更新：

$$
\tau^{(k+1)} = \tau^{(k)} - \eta_\tau \frac{\partial \mathcal{L}}{\partial \tau}
$$

$$
\mu^{(k+1)} = \mu^{(k)} + \eta_\mu \left(\sum_i \sigma_\beta(\text{conf}_i - \tau^{(k)}) - c\right)
$$

**收敛性**：当 $\sum_i \sigma_\beta \to c$，$\mu$ 停止更新，$\tau$ 收敛到使恰好 $c$ 个 proposal 通过的阈值。

#### 2.2.4 简化实现：二分搜索阈值

由于单图 $c$ 已知且 proposal 数有限（500），可直接二分搜索 $\tau$：

```python
def find_threshold_for_count(scores, target_count, tau_low=0.0, tau_high=1.0, iters=20):
    """二分搜索使 top-k 恰好等于 target_count 的阈值"""
    for _ in range(iters):
        tau_mid = (tau_low + tau_high) / 2
        count = (scores > tau_mid).sum().item()
        if count > target_count:
            tau_low = tau_mid  # 阈值太低, 提高
        else:
            tau_high = tau_mid  # 阈值太高, 降低
    return tau_high
```

复杂度 $O(N \log(1/\epsilon))$，对 $N=500$ 可忽略。

### 2.3 路径 C：计数分支辅助监督 (Counting Branch Auxiliary)

#### 2.3.1 计数预测头

在扩散头之外，加一个轻量计数分支，从图像特征预测 $c$：

$$
\hat{c} = \text{CountHead}(\text{FPN features})
$$

训练时用 L1 损失：

$$
\mathcal{L}_{\text{count}} = |\hat{c} - c_{\text{gt}}|
$$

#### 2.3.2 与路径 A/B 的关系

- 路径 A 需要 $c$ 作为输入：训练时用 $c_{\text{gt}}$，推理时用 $\hat{c}$（路径 C 提供）
- 路径 B 需要 $c$ 作为约束：同上
- **路径 C 是 A/B 的 enabler**，使整个流程不依赖外部计数输入

### 3.1 计数编码模块

新建 [ldmdet/core/count_conditioning.py](../../ldmdet/core/count_conditioning.py)：

```python
"""计数条件化模块: 将染色体计数 c 编码为嵌入向量"""

import torch
import torch.nn as nn

from ldmdet.diffusion.embeddings import SinusoidalPositionEmbeddings


class CountConditioning(nn.Module):
    """计数条件化编码.

    将 c ∈ {44,...,48} 编码为 feat_channels*4 维向量,
    与 time_emb 相加后注入 AdaLN-Zero.

    支持 classifier-free guidance: 训练时以 p_drop 概率置零.
    """

    def __init__(
        self,
        feat_channels: int = 256,
        p_drop: float = 0.1,
        count_min: int = 44,
        count_max: int = 48,
    ):
        super().__init__()
        self.feat_channels = feat_channels
        self.p_drop = p_drop
        self.count_min = count_min
        self.count_max = count_max

        self.count_embed = SinusoidalPositionEmbeddings(feat_channels * 4)
        self.count_mlp = nn.Sequential(
            nn.Linear(feat_channels * 4, feat_channels * 4),
            nn.SiLU(),
            nn.Linear(feat_channels * 4, feat_channels * 4),
        )

    def forward(self, count: torch.Tensor) -> torch.Tensor:
        """
        Args:
            count: [bs] 染色体计数 (long)

        Returns:
            [bs, feat_channels*4] 计数嵌入
        """
        # 训练时 CFG dropout
        if self.training and self.p_drop > 0:
            mask = torch.rand_like(count, dtype=torch.float) > self.p_drop
            count = count * mask  # 0 表示无条件

        # 归一化到 [0, 1] 范围 (SinusoidalPositionEmbeddings 对小数值更稳定)
        count_norm = (count.float() - self.count_min) / max(
            self.count_max - self.count_min, 1
        )
        count_norm = count_norm.clamp(0.0, 1.0) * 1000  # 缩放到 embedding 期望范围
        emb = self.count_mlp(self.count_embed(count_norm.long()))
        return emb
```

### 3.3 推理时拉格朗日约束

新建 [ldmdet/inference/count_constrained_nms.py](../../ldmdet/inference/count_constrained_nms.py)：

```python
"""计数约束 NMS: 调整阈值使最终检测数等于目标计数"""

import torch
from torch import Tensor


def count_constrained_nms(
    boxes: Tensor,
    scores: Tensor,
    labels: Tensor,
    target_count: int,
    iou_threshold: float = 0.5,
    min_keep: int = 10,
    max_iters: int = 20,
) -> Tensor:
    """计数约束 NMS.

    通过二分搜索置信度阈值, 使 NMS 后检测数尽可能接近 target_count.

    Args:
        boxes: [N, 4] 预测框
        scores: [N] 置信度
        labels: [N] 类别
        target_count: 目标检测数 (如 46)
        iou_threshold: NMS IoU 阈值
        min_keep: 最少保留数 (防止过度抑制)
        max_iters: 二分搜索迭代

    Returns:
        keep: [K] 保留的索引
    """
    from torchvision.ops import batched_nms

    tau_low, tau_high = 0.0, float(scores.max().item())
    best_keep = None

    for _ in range(max_iters):
        tau_mid = (tau_low + tau_high) / 2
        mask = scores > tau_mid
        if mask.sum() == 0:
            tau_high = tau_mid
            continue

        keep = batched_nms(
            boxes[mask], scores[mask], labels[mask], iou_threshold
        )
        count = keep.shape[0]

        if count > target_count:
            tau_low = tau_mid  # 提高阈值减少检测
        elif count < target_count:
            tau_high = tau_mid  # 降低阈值增加检测
        else:
            best_keep = mask.nonzero(as_tuple=True)[0][keep]
            break

        # 保留最接近 target_count 的结果
        if best_keep is None or abs(count - target_count) < abs(
            (best_keep.shape[0] if best_keep is not None else 0) - target_count
        ):
            best_keep = mask.nonzero(as_tuple=True)[0][keep]

    # 兜底: 至少保留 min_keep 个
    if best_keep is None or best_keep.shape[0] < min_keep:
        keep = batched_nms(boxes, scores, labels, iou_threshold)
        best_keep = keep[:max(target_count, min_keep)]

    return best_keep
```

### 3.4 计数分支（路径 C）

新建 [ldmdet/core/counting_branch.py](../../ldmdet/core/counting_branch.py)：

```python
"""计数分支: 从 FPN 特征预测染色体总数"""

import torch
import torch.nn as nn


class CountingBranch(nn.Module):
    """轻量计数分支.

    从 FPN 各层特征池化后预测染色体总数 c.
    输出范围 [44, 48] (覆盖常见核型).

    结构: 多尺度池化 → 拼接 → MLP → softmax over {44,...,48}
    """

    def __init__(
        self,
        feat_channels: int = 256,
        count_min: int = 44,
        count_max: int = 48,
    ):
        super().__init__()
        self.count_min = count_min
        self.count_max = count_max
        num_classes = count_max - count_min + 1

        # 多尺度自适应池化
        self.pools = nn.ModuleList([
            nn.AdaptiveAvgPool2d(1) for _ in range(4)  # P2-P5
        ])
        self.mlp = nn.Sequential(
            nn.Linear(feat_channels * 4, feat_channels * 2),
            nn.SiLU(),
            nn.Linear(feat_channels * 2, num_classes),
        )

    def forward(self, features: list[torch.Tensor]) -> torch.Tensor:
        """
        Args:
            features: [P2, P3, P4, P5] FPN 特征

        Returns:
            logits: [bs, num_count_classes] 计数分类 logits
            pred_count: [bs] 预测计数 (argmax + count_min)
        """
        pooled = [pool(f).flatten(1) for pool, f in zip(self.pools, features)]
        concat = torch.cat(pooled, dim=1)
        logits = self.mlp(concat)
        pred_count = logits.argmax(dim=-1) + self.count_min
        return logits, pred_count
```

## 5. 预期收益与风险

### 收益

1. **计数准确性**：$\|N_{\text{pred}} - c\|$ 从典型 5-10 降到 1-2
2. **异常核型**：47 条核型不再被压回 46
3. **临床可用性**：计数是核型分析的核心指标，提升临床价值
4. **免费先验**：$c$ 几乎免费可得，无额外标注成本

### 风险

1. **过拟合计数**：路径 A 可能牺牲定位精度换取计数正确
2. **CFG 调参**：$w$ 过大会导致样本质量下降
3. **路径 C 误差传播**：计数分支预测错误会传导到 A/B
4. **异常核型稀少**：训练集中 47 条样本少，可能学不好

### 缓解

- 路径 A 用小 $w$（0.5-1.0），避免过强引导
- 路径 C 用分类而非回归，对异常核型更鲁棒
- 路径 B 作为推理时后处理，不依赖训练分布

### 7.4 现象分析

1. **mAP 大幅下降**：0.726 vs SOTA 0.753，差距 2.7 个百分点，远超方向一（-0.007）。验收标准"mAP 不低于基线"未通过。

2. **APs 严重下降**：0.448 vs 0.521，小目标检测退步 7.3 个百分点。计数约束 NMS 可能过度抑制了小目标（低置信度但正确的检测被阈值过滤掉）。

3. **AP50/AP75 全面落后**：0.916/0.808 vs 0.943/0.844，定位和匹配精度均下降。计数分支的额外损失可能干扰了主检测任务的优化。

4. **loss_count 未充分收敛**：在 0.2-0.4 波动，计数分支预测仍有误差。路径 B 依赖路径 C 的预测计数，误差会传导到约束阈值的计算。

5. **训练后期波动**：epoch 97 best 0.726 后，mAP 在 0.714-0.721 波动，未再创新高，与方向一类似。

6. **路径 A 未实现**：文档核心创新点（CFG 条件化生成）未实现，当前实验仅测试了推理时约束（B）+ 辅助监督（C），无法评估条件化生成对扩散过程本身的影响。

### 7.5 根因分析

1. **计数约束与检测质量冲突**：路径 B 通过调整置信度阈值强制满足计数约束，但高置信度 ≠ 正确检测。当模型预测的置信度分布不准确时，强制计数约束会保留低质量检测或丢弃高质量检测。

2. **辅助损失干扰主任务**：`loss_count` 的梯度通过 FPN 特征回传，可能干扰主检测分支的特征学习。`count_loss_weight=1.0` 可能过大。

3. **与方向一相同的根本问题**：在 Rectified Flow 框架中，推理时后处理（路径 B）无法改善扩散过程本身的生成质量；辅助监督（路径 C）对 Transformer 表示层的影响有限。

### 7.6 结论

**方向二（计数先验约束）路径 B+C 实验失败**。best mAP=0.726，低于 SOTA 0.753 达 2.7 个百分点，验收未通过。核心创新点路径 A（CFG 条件化生成）未实现，但路径 B+C 的负面结果已表明：推理时计数约束 + 辅助计数监督的组合不仅无益，反而有害。

**状态**：⏸ 暂停。若继续，应优先实现路径 A（CFG 条件化生成），评估条件化对扩散过程本身的影响，而非仅依赖推理时后处理。
