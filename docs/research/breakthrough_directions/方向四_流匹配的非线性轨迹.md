# 方向四：流匹配的非线性轨迹 (Nonlinear Trajectories for Flow Matching)

> **目标**：突破 1-RectFlow 直线路径对尺度不敏感的局限，引入尺度条件化噪声调度和 mini-batch OT 流匹配，使传输路径适应不同尺度目标，提升小目标检测和少步采样精度。
>
> **理论依据**：
> - Flow Matching: Lipman et al., "Flow Matching for Generative Modeling" (ICLR 2023)
> - Mini-batch OT: Pooladian et al., "Multisample Flow Matching" (NeurIPS 2023)
> - Rectified Flow: Liu et al., "Flow Straight and Fast" (ICLR 2023)
>
> **当前代码位置**：[ldmdet/diffusion/rectified_flow.py](../../ldmdet/diffusion/rectified_flow.py), [ldmdet/diffusion/sampling.py](../../ldmdet/diffusion/sampling.py)

---

## 1. 问题分析：直线路径的局限

### 1.1 当前实现

[rectified_flow.py:30-37](../../ldmdet/diffusion/rectified_flow.py#L30-L37) 使用直线路径：

```python
x_t = (1.0 - t_view) * x_start + t_view * x_noise
velocity = x_noise - x_start   # 常速度
```

这是 1-RectFlow 的标准形式：给定初始耦合 $(x_0, x_1)$，路径为连接两点的直线。

### 1.2 数学问题

**问题 1：尺度不敏感**

直线路径对所有目标用相同的 $t$ 调度。但染色体框尺度差异大：
- 小框（如着丝粒区域）：边长 ~0.02（归一化）
- 大框（如完整染色体）：边长 ~0.15

小框的"信号能量" $\|x_0\|^2$ 远小于大框，在相同 $t$ 下，小框的 SNR 更低，去噪更困难。直线路径无法自适应。

**问题 2：耦合次优**

1-RectFlow 的直线性依赖于**给定耦合** $(x_0, x_1)$。当前 GHSS 给出的耦合是组内 OT 配对，但这是**静态的**——训练前确定 $x_1$，路径固定。若耦合不佳（如 $x_0$ 和 $x_1$ 距离远），路径仍需弯曲。

**问题 3：少步采样精度**

直线路径在 1 步采样时精确（$v$ 为常数），但 2-6 步时，若实际流形弯曲，Euler/Heun 会累积误差。当前 [rectified_flow.py:60-78](../../ldmdet/diffusion/rectified_flow.py#L60-L78) 的 Heun step 假设局部线性，对弯曲路径二阶项失效。

## 2. 数学推导

### 2.1 尺度条件化噪声调度

#### 2.1.1 尺度依赖的 SNR

定义目标尺度 $s = \sqrt{\text{area}(x_0)}$。尺度条件化调度让小目标的去噪更早（更陡的调度）：

$$
x_t = \alpha(t, s) \, x_0 + \sigma(t, s) \, x_1
$$

其中 $\alpha, \sigma$ 满足：
- $\alpha(0, s) = 1, \sigma(0, s) = 0$（纯数据）
- $\alpha(1, s) = 0, \sigma(1, s) = 1$（纯噪声）
- $\frac{\alpha(t, s)}{\sigma(t, s)}$ 对小 $s$ 更快增长（小目标更快去噪）

#### 2.1.2 具体形式

**方案 A：尺度调制 RF**

$$
\alpha(t, s) = 1 - t^{1/\kappa(s)}, \quad \sigma(t, s) = t^{1/\kappa(s)}
$$

其中 $\kappa(s) = 1 + \lambda (s_{\max} - s) / s_{\max}$，$\lambda$ 控制调制强度。

- $s = s_{\max}$（大目标）：$\kappa = 1$，退化为标准线性 RF
- $s \to 0$（小目标）：$\kappa > 1$，$t^{1/\kappa}$ 增长更慢，$\alpha$ 更快接近 1

**方案 B：SNR 重加权**

保持线性路径，但损失按尺度加权：

$$
\mathcal{L}(t, s) = w(t, s) \cdot \|v_\theta(x_t, t) - (x_1 - x_0)\|^2
$$

$$
w(t, s) = \frac{1}{\text{SNR}(t) + \epsilon(s)}, \quad \epsilon(s) \propto s^2
$$

小目标的 $\epsilon$ 小，高噪声时损失权重更高，迫使模型更努力学习小目标。

#### 2.1.3 速度场推导

对 $x_t = \alpha(t,s) x_0 + \sigma(t,s) x_1$，速度：

$$
v(t, s) = \frac{dx_t}{dt} = \alpha'(t,s) x_0 + \sigma'(t,s) x_1
$$

方案 A 下：

$$
\alpha'(t,s) = -\frac{1}{\kappa(s)} t^{1/\kappa(s) - 1}, \quad \sigma'(t,s) = \frac{1}{\kappa(s)} t^{1/\kappa(s) - 1}
$$

$$
v(t, s) = \frac{t^{1/\kappa(s) - 1}}{\kappa(s)} (x_1 - x_0)
$$

**关键**：速度不再是常数，而是 $t$ 的函数。采样时需数值积分。

### 2.2 Mini-Batch OT 流匹配

#### 2.2.1 动态耦合

不再固定 $x_1$，而是在每个 $t$ 处由 mini-batch OT 动态决定最优 $x_1$：

$$
v_\theta(x, t) = \mathbb{E}_{x_1 \sim \pi^*(\cdot | x, t)}[x_1 - x]
$$

其中 $\pi^*$ 是 mini-batch 内的 OT 耦合：

$$
\pi^* = \arg\min_{\pi \in \Pi(\mu, \nu)} \int \|x_0 - x_1\|^2 d\pi
$$

#### 2.2.2 训练目标

$$
\mathcal{L}_{\text{OT-FM}} = \mathbb{E}_{t, x_0, \{x_1^{(k)}\}_{k=1}^K}\left[\left\|v_\theta(x_t, t) - \frac{1}{K}\sum_{k=1}^K (x_1^{(k)*} - x_0)\right\|^2\right]
$$

其中 $\{x_1^{(k)*}\}$ 是 mini-batch 内与 $x_0$ OT 配对的前 $K$ 个噪声。

#### 2.2.3 与 GHSS 的关系

GHSS 是**训练前**的静态 OT 耦合（确定 $x_0 \to x_1$ 配对）。Mini-batch OT 流匹配是**训练中**的动态耦合（每个 batch 重新配对）。两者互补：
- GHSS 提供组内结构先验
- Mini-batch OT 提供全局最优传输

### 2.3 2-RectFlow 迭代

#### 2.3.1 直线化

1-RectFlow 训练后，用模型生成 $(x_0, x_1)$ 对，重新训练 2-RectFlow：

$$
x_1^{(2)} = \text{ODE\_solve}(v_\theta^{(1)}, x_0)
$$

新耦合 $(x_0, x_1^{(2)})$ 的路径更直（因为 $x_1^{(2)}$ 是模型生成的"去噪后噪声"，与 $x_0$ 更对齐）。

#### 2.3.2 路径曲率

路径曲率：

$$
\kappa(t) = \left\|\frac{dv}{dt}\right\| = \left\|\frac{d^2x}{dt^2}\right\|
$$

1-RectFlow: $\kappa = 0$（直线，但耦合次优时实际流形弯曲）
2-RectFlow: $\kappa \approx 0$（耦合更优，路径更接近真实直线）

## 3. 实现方案

### 3.1 尺度条件化 RF

新建 [ldmdet/diffusion/scale_conditioned_rf.py](../../ldmdet/diffusion/scale_conditioned_rf.py)：

```python
"""尺度条件化 Rectified Flow"""

import torch
from torch import Tensor
from typing import Optional, Tuple


class ScaleConditionedRF:
    """尺度条件化 RF: 小目标更陡的噪声调度.

    路径: x_t = α(t,s) x_0 + σ(t,s) x_1
    其中 s = sqrt(area(x_0)), α/σ 由 κ(s) 调制.

    Args:
        lambda_mod: 调制强度 (0=标准 RF, 越大尺度差异越显著)
        s_max: 参考最大尺度 (归一化面积平方根)
    """

    def __init__(self, lambda_mod: float = 0.5, s_max: float = 0.15):
        self.lambda_mod = lambda_mod
        self.s_max = s_max

    def compute_kappa(self, scales: Tensor) -> Tensor:
        """计算尺度调制系数 κ(s) = 1 + λ(s_max - s)/s_max

        Args:
            scales: [bs, N] 每个框的尺度 sqrt(area)

        Returns:
            kappa: [bs, N] 同形状
        """
        return 1.0 + self.lambda_mod * (self.s_max - scales) / self.s_max.clamp(min=1e-6)

    def q_sample(
        self,
        x_start: Tensor,
        x_noise: Optional[Tensor] = None,
        t: Optional[Tensor] = None,
        scales: Optional[Tensor] = None,
    ) -> Tuple[Tensor, Tensor, Tensor]:
        """前向加噪: x_t = α(t,s) x_0 + σ(t,s) x_1

        Args:
            x_start: [bs, N, D] 数据 (GT 框)
            x_noise: [bs, N, D] 噪声, 若 None 则随机
            t: [bs] 或 [bs, N] 时间, 若 None 则随机
            scales: [bs, N] 框尺度, 若 None 则用 1 (退化为标准 RF)

        Returns:
            x_t: 加噪样本
            velocity: 目标速度
            t_eff: 有效时间 t^{1/κ(s)} (用于损失加权)
        """
        if x_noise is None:
            x_noise = torch.randn_like(x_start)
        if t is None:
            t = torch.rand((x_start.shape[0],), device=x_start.device)
        if scales is None:
            scales = torch.ones(x_start.shape[:2], device=x_start.device)

        # 广播 t 到 [bs, N]
        if t.dim() == 1:
            t = t.unsqueeze(1).expand_as(scales)

        kappa = self.compute_kappa(scales)  # [bs, N]
        t_eff = t.pow(1.0 / kappa)  # [bs, N] 有效时间

        # 广播到 x_start 的维度
        t_view = t_eff.unsqueeze(-1)  # [bs, N, 1]
        x_t = (1.0 - t_view) * x_start + t_view * x_noise
        velocity = x_noise - x_start
        return x_t, velocity, t_eff

    def get_velocity(self, x_t, x0_pred, t, scales):
        """v_t = (t_eff^{κ-1} / κ) * (x_1 - x_0) ≈ (x_t - x_0_pred) / t_eff"""
        kappa = self.compute_kappa(scales)
        if t.dim() == 1:
            t = t.unsqueeze(1).expand_as(scales)
        t_eff = t.pow(1.0 / kappa)
        t_view = t_eff.unsqueeze(-1).clamp(min=1e-5)
        return (x_t - x0_pred) / t_view

    def step(self, x_t, x0_pred, t_curr, t_next, scales):
        """Euler step with scale-conditioned schedule"""
        if isinstance(t_curr, (int, float)):
            t_curr = torch.full(scales.shape, t_curr, device=x_t.device)
        if isinstance(t_next, (int, float)):
            t_next = torch.full(scales.shape, t_next, device=x_t.device)

        kappa = self.compute_kappa(scales)
        t_eff_curr = t_curr.pow(1.0 / kappa)
        t_eff_next = t_next.pow(1.0 / kappa)

        # 在 t_eff 空间做 Euler
        v = (x_t - x0_pred) / t_eff_curr.unsqueeze(-1).clamp(min=1e-5)
        dt_eff = (t_eff_next - t_eff_curr).unsqueeze(-1)
        return x_t + dt_eff * v
```

### 3.2 Mini-Batch OT 流匹配

新建 [ldmdet/diffusion/ot_flow_matching.py](../../ldmdet/diffusion/ot_flow_matching.py)：

```python
"""Mini-batch OT 流匹配"""

import torch
from torch import Tensor
from typing import Optional, Tuple

from ldmdet.coupling._sinkhorn_ops import sinkhorn_transport


class OTFlowMatching:
    """Mini-batch OT 流匹配.

    训练时每个 batch 内动态计算 OT 耦合, 而非固定 (x_0, x_1) 配对.
    速度目标为 OT 配对后的 (x_1 - x_0).

    Args:
        epsilon: Sinkhorn 熵正则化
        num_iters: Sinkhorn 迭代
        ot_every_step: 是否每步重算 OT (True=动态, False=仅初始)
    """

    def __init__(
        self,
        epsilon: float = 1.0,
        num_iters: int = 10,
        ot_every_step: bool = False,
    ):
        self.epsilon = epsilon
        self.num_iters = num_iters
        self.ot_every_step = ot_every_step

    def compute_ot_coupling(
        self,
        x_start: Tensor,  # [N, D]
        x_noise: Tensor,  # [N, D]
    ) -> Tuple[Tensor, Tensor]:
        """计算 mini-batch OT 耦合.

        Returns:
            x_start_coupled: [N, D] 重排后的 x_start
            x_noise_coupled: [N, D] 重排后的 x_noise
        """
        N = x_start.shape[0]
        cost = torch.cdist(x_start, x_noise, p=2)  # [N, N]

        # Sinkhorn → 传输矩阵
        transport = sinkhorn_transport(
            cost, epsilon=self.epsilon, num_iters=self.num_iters
        )

        # Argmax 耦合 (确定性)
        coupled_idx = transport.argmax(dim=1)  # [N]
        return x_start, x_noise[coupled_idx]

    def q_sample(
        self,
        x_start: Tensor,
        x_noise: Optional[Tensor] = None,
        t: Optional[Tensor] = None,
    ) -> Tuple[Tensor, Tensor]:
        """OT 耦合的前向加噪.

        Args:
            x_start: [bs, N, D]
            x_noise: [bs, N, D]
            t: [bs]

        Returns:
            x_t: 加噪样本
            velocity: OT 耦合速度
        """
        if x_noise is None:
            x_noise = torch.randn_like(x_start)
        if t is None:
            t = torch.rand((x_start.shape[0],), device=x_start.device)

        bs = x_start.shape[0]
        x_start_coupled = []
        x_noise_coupled = []

        for b in range(bs):
            s_c, n_c = self.compute_ot_coupling(x_start[b], x_noise[b])
            x_start_coupled.append(s_c)
            x_noise_coupled.append(n_c)

        x_start_c = torch.stack(x_start_coupled)
        x_noise_c = torch.stack(x_noise_coupled)

        t_view = t.view(-1, 1, 1)
        x_t = (1.0 - t_view) * x_start_c + t_view * x_noise_c
        velocity = x_noise_c - x_start_c
        return x_t, velocity
```

### 3.3 2-RectFlow 迭代训练

```python
"""2-RectFlow 迭代训练脚本"""

import torch
from ldmdet.diffusion.rectified_flow import RectifiedFlow


class TwoStepRectFlowTrainer:
    """2-RectFlow: 用 1-RectFlow 模型生成新耦合, 再训练 2-RectFlow.

    步骤:
    1. 用 1-RectFlow 模型从 x_0 前向到 x_1 (生成 x_1^{(2)})
    2. 用新耦合 (x_0, x_1^{(2)}) 训练 2-RectFlow
    3. 2-RectFlow 的路径更直, 少步采样更准
    """

    def __init__(self, rf_v1: RectifiedFlow, model_v1):
        self.rf_v1 = rf_v1
        self.model_v1 = model_v1  # 已训练的 1-RectFlow 模型

    @torch.no_grad()
    def generate_new_coupling(
        self, x_start: torch.Tensor, num_steps: int = 10
    ) -> torch.Tensor:
        """用 1-RectFlow 从 x_0 生成 x_1^{(2)}.

        Args:
            x_start: [bs, N, D] 真实框
            num_steps: ODE 求解步数

        Returns:
            x1_new: [bs, N, D] 新的噪声端点
        """
        x_t = x_start.clone()
        dt = 1.0 / num_steps

        for step in range(num_steps):
            t_curr = step * dt
            t_next = (step + 1) * dt
            x0_pred, _ = self.model_v1(x_t, torch.full(
                (x_t.shape[0],), t_curr, device=x_t.device
            ))
            x_t = self.rf_v1.step(x_t, x0_pred, t_curr, t_next)

        return x_t  # x_1^{(2)}
```

### 4.4 路径曲率测量

计算训练后模型的路径曲率：

$$
\kappa(t) = \left\|\frac{dv_\theta}{dt}\right\| = \left\|\frac{v_\theta(x_{t+\Delta t}) - v_\theta(x_t)}{\Delta t}\right\|

预期：E4.2/E4.4 的 $\kappa$ 显著低于 E4.0。

### 4.5 消融

- 尺度条件化 $\lambda \in \{0, 0.25, 0.5, 1.0\}$
- Mini-batch OT $\varepsilon \in \{0.5, 1.0, 5.0\}$
- 2-RectFlow 迭代次数 $\in \{1, 2, 3\}$

## 5. 预期收益与风险

### 收益

1. **小目标 mAP**：尺度条件化预期提升小目标 AP 2-5%
2. **少步采样**：2-RectFlow 在 1-3 步时精度衰减减少 30-50%
3. **路径质量**：Mini-batch OT 使路径更直，理论上限更高
4. **理论优雅**：消除线性路径的尺度不敏感假设

### 风险

1. **实现复杂度**：尺度条件化需修改采样器、损失、box_renewal 多处
2. **训练不稳定**：动态 OT 耦合可能引入 batch 内方差
3. **2-RectFlow 成本**：需训练两个模型，存储和计算翻倍
4. **与 box_renewal 冲突**：box_renewal 每步重置 proposal，可能削弱路径优化的收益

### 缓解

- 尺度条件化用小 $\lambda$（0.5），避免过度调制
- Mini-batch OT 用较大 $\varepsilon$（1.0），保证耦合稳定
- 2-RectFlow 作为可选增强，不强制
