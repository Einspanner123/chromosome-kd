# 方向一：非平衡最优传输耦合 (Unbalanced Optimal Transport Coupling)

> **目标**：突破 GHSS 耦合策略中强制平衡边缘约束的理论局限，引入非平衡 OT 框架，自然适应染色体组内 GT 数极不均匀的真实分布。
>
> **理论依据**：Chizat et al., "Scaling Algorithms for Unbalanced Transport Problems" (2018)
> **当前代码位置**：[ldmdet/coupling/ghss.py](../../ldmdet/coupling/ghss.py), [ldmdet/coupling/_sinkhorn_ops.py](../../ldmdet/coupling/_sinkhorn_ops.py)

---

## 1. 问题分析：当前 GHSS 的理论局限

### 1.1 当前实现

[ghss.py:99-103](../../ldmdet/coupling/ghss.py#L99-L103) 对每个染色体组 $g$ 构造边缘分布：

```python
proposals_per_gt = max(N_g // K_g, 1)
gt_mass = torch.full((K_g,), proposals_per_gt / N_g, device=device)
b = gt_mass / gt_mass.sum()   # 强制 sum(b) = 1
```

行边缘 $a = \mathbf{1}_N / N$，列边缘 $b$ 被归一化为 $\sum b = 1 = \sum a$，然后调用标准 Sinkhorn。

### 1.2 数学问题

标准 Sinkhorn 求解的是 **Kantorovich 平衡传输**：

$$
P^* = \arg\min_{P \in \Pi(a,b)} \langle P, C \rangle - \varepsilon H(P)
$$

其中 $\Pi(a,b) = \{P \geq 0 : P\mathbf{1} = a, P^\top\mathbf{1} = b\}$ 要求**精确匹配边缘**。

**局限 1：质量扭曲**。当 $N_g = 60, K_g = 7$（C 组），每个 GT 被强制分配 $60/7 \approx 8.57$ 个 proposal。但实际中某些 GT 可能处于图像边缘、遮挡、低对比度区域，本应吸引更少 proposal。强制平均分配导致远离 GT 的 proposal 被错误"拉"过来。

**局限 2：组间不均衡放大**。组内 GT 数 $K_g$ 跨组差异巨大（B 组 2 类 vs C 组 7 类），强制平衡使小 $K_g$ 组的每个 GT 被过度采样，大 $K_g$ 组的每个 GT 欠采样。

**局限 3：异常核型失效**。当某组 GT 数为 0（如 Sex 组缺失），当前代码用 `max(N_g // K_g, 1)` 兜底，但 $K_g=0$ 时 `col_mass` 为空，传输矩阵退化为全零，浪费该组分配的 $N_g$ 个 proposal。

## 2. 数学推导：非平衡最优传输

### 2.1 非平衡 OT 目标函数

放松边缘约束，引入 KL 散度惩罚（Chizat 2018）：

$$
\min_{P \geq 0} \mathcal{F}(P) = \langle P, C \rangle - \varepsilon H(P) + \lambda_1 \text{KL}(P\mathbf{1} \| a) + \lambda_2 \text{KL}(P^\top\mathbf{1} \| b)
$$

其中：
- $H(P) = -\sum_{ij} P_{ij}(\log P_{ij} - 1)$ 为熵正则项
- $\text{KL}(u \| v) = \sum_i u_i \log(u_i/v_i) - u_i + v_i$（广义 KL，允许 $u \neq v$ 的总和）
- $\lambda_1, \lambda_2 > 0$ 为边缘松弛系数

**极限行为**：
- $\lambda_1, \lambda_2 \to \infty$：退化为标准平衡 Sinkhorn
- $\lambda_1, \lambda_2 \to 0$：完全放松，$P$ 退化为对 $\langle P, C \rangle - \varepsilon H(P)$ 的无约束最小化（即 $P_{ij} \propto \exp(-C_{ij}/\varepsilon)$，类似 Sinkhorn 一步迭代）
- $\lambda_1 \neq \lambda_2$：允许行/列不同程度松弛

### 2.2 半平衡 Sinkhorn 迭代

对 $\mathcal{F}(P)$ 求 KKT 条件，得最优 $P$ 的形式：

$$
P_{ij}^* = u_i \, K_{ij} \, v_j, \quad K_{ij} = \exp(-C_{ij}/\varepsilon)
$$

其中 $u, v$ 由以下不动点迭代求解（**关键差异**：多了 $\phi$ 函数）：

$$
u_i = \left(\frac{a_i}{(Kv)_i}\right)^{\lambda_1 / (\varepsilon + \lambda_1)}
$$

$$
v_j = \left(\frac{b_j}{(K^\top u)_j}\right)^{\lambda_2 / (\varepsilon + \lambda_2)}
$$

**对比标准 Sinkhorn**（平衡情形 $u_i = a_i / (Kv)_i$）：

| 项 | 标准 Sinkhorn | 非平衡 Sinkhorn |
|----|--------------|----------------|
| $u$ 更新 | $u_i = a_i / (Kv)_i$ | $u_i = (a_i / (Kv)_i)^{\lambda_1/(\varepsilon+\lambda_1)}$ |
| 指数 | 1 | $\lambda_1/(\varepsilon+\lambda_1) \in (0, 1)$ |
| 边缘 | 严格满足 $P\mathbf{1}=a$ | 软满足，KL 惩罚 |

**指数的物理意义**：当 $\lambda_1 \ll \varepsilon$，指数 $\to 0$，$u_i \to 1$，行约束几乎不生效；当 $\lambda_1 \gg \varepsilon$，指数 $\to 1$，退化为标准 Sinkhorn。

### 2.3 对数域稳定实现

为数值稳定性，在对数域迭代。令 $\tilde{u}_i = \log u_i$，$\tilde{v}_j = \log v_j$，$\alpha = \lambda_1/(\varepsilon+\lambda_1)$，$\beta = \lambda_2/(\varepsilon+\lambda_2)$：

$$
\tilde{u}_i = \alpha \left(\log a_i - \text{logsumexp}_j(\tilde{v}_j - C_{ij}/\varepsilon)\right)
$$

$$
\tilde{v}_j = \beta \left(\log b_j - \text{logsumexp}_i(\tilde{u}_i - C_{ij}/\varepsilon)\right)
$$

最终 $P_{ij} = \exp(\tilde{u}_i + \tilde{v}_j - C_{ij}/\varepsilon)$。

### 2.4 空组处理（$K_g = 0$）

非平衡 OT 自然处理 $K_g = 0$：此时 $b$ 为空向量，列约束消失，$P$ 退化为 $N_g \times 0$ 空矩阵。**工程上**应将这些 proposal 重新分配给其他组，或保留为"背景 proposal"（不参与 GT 匹配，但允许模型学习拒绝）。

## 3. 实现方案

### 3.1 新增 `unbalanced_sinkhorn_transport`

在 [ldmdet/coupling/_sinkhorn_ops.py](../../ldmdet/coupling/_sinkhorn_ops.py) 新增函数：

```python
def unbalanced_sinkhorn_transport(
    cost: Tensor,
    epsilon: float,
    num_iters: int = 20,
    row_mass: Optional[Tensor] = None,
    col_mass: Optional[Tensor] = None,
    lambda_row: float = 1.0,
    lambda_col: float = 1.0,
) -> Tensor:
    """非平衡 Sinkhorn 传输 (Chizat et al., 2018).

    P = argmin <P,C> - ε H(P) + λ_row KL(P1||a) + λ_col KL(P^T1||b)

    Args:
        cost: [N, K] 代价矩阵
        epsilon: 熵正则化
        num_iters: 迭代次数
        row_mass: [N] 行边缘目标 (默认均匀)
        col_mass: [K] 列边缘目标 (默认均匀)
        lambda_row: 行边缘松弛系数 (∞ → 标准 Sinkhorn)
        lambda_col: 列边缘松弛系数

    Returns:
        [N, K] 传输矩阵 (行和不必等于 a)
    """
    N, K = cost.shape
    device = cost.device

    if row_mass is None:
        row_mass = torch.ones(N, device=device) / max(N, 1)
    if col_mass is None:
        col_mass = torch.ones(K, device=device) / max(K, 1)

    eps = max(epsilon, 1e-6)
    # 软约束指数: λ/(ε+λ), λ→∞ 时 → 1 (标准 Sinkhorn)
    alpha = lambda_row / (eps + lambda_row)
    beta = lambda_col / (eps + lambda_col)

    log_K = -cost / eps  # [N, K]
    log_u = torch.zeros(N, device=device)
    log_v = torch.zeros(K, device=device)
    log_a = torch.log(row_mass.clamp_min(1e-10))
    log_b = torch.log(col_mass.clamp_min(1e-10))

    for _ in range(num_iters):
        # log_u = α * (log_a - logsumexp_j(log_K + log_v))
        log_u = alpha * (log_a - torch.logsumexp(log_K + log_v.unsqueeze(0), dim=1))
        # log_v = β * (log_b - logsumexp_i(log_K + log_u))
        log_v = beta * (log_b - torch.logsumexp(log_K + log_u.unsqueeze(1), dim=0))

    return torch.exp(log_u.unsqueeze(1) + log_K + log_v.unsqueeze(0))
```

### 3.2 新增 `UnbalancedGHSSCoupling` 耦合策略

在 [ldmdet/coupling/ghss.py](../../ldmdet/coupling/ghss.py) 同级新建 `unbalanced_ghss.py`：

```python
"""非平衡 GHSS: 组内非平衡 OT 耦合"""

from typing import Optional
import torch
from torch import Tensor

from ldmdet.coupling._sinkhorn_ops import (
    ot_multinomial, unbalanced_sinkhorn_transport
)
from ldmdet.coupling.base import CouplingStrategy, register_coupling
from ldmdet.utils.constants import CHROMO_GROUP_OF_CLASS


@register_coupling('unbalanced_ghss')
class UnbalancedGHSSCoupling(CouplingStrategy):
    """非平衡 GHSS 耦合.

    与标准 GHSS 的区别:
    1. 组内 OT 用非平衡 Sinkhorn, 允许边缘松弛
    2. 不强制 proposals_per_gt 均分, 让 OT 自然决定
    3. 空组 (K_g=0) 的 proposal 分配给最大组

    Args:
        epsilon: 熵正则化 (默认 5.0)
        num_iters: Sinkhorn 迭代 (默认 20)
        lambda_row: 行边缘松弛 (默认 1.0, 越小越松)
        lambda_col: 列边缘松弛 (默认 1.0)
        sample_seed: 随机种子
    """

    def __init__(
        self,
        epsilon: float = 5.0,
        num_iters: int = 20,
        lambda_row: float = 1.0,
        lambda_col: float = 1.0,
        sample_seed: Optional[int] = None,
    ):
        super().__init__()
        self.epsilon = epsilon
        self.num_iters = num_iters
        self.lambda_row = lambda_row
        self.lambda_col = lambda_col
        self.sample_seed = sample_seed

        self.register_buffer(
            '_chromo_group_of_class',
            torch.tensor(CHROMO_GROUP_OF_CLASS, dtype=torch.long),
            persistent=False,
        )

    def couple(
        self,
        noise: Tensor,
        gt_diffusion: Tensor,
        gt_labels: Tensor,
        device: torch.device,
    ) -> tuple[Tensor, Tensor]:
        N = noise.shape[0]
        num_gt = gt_labels.shape[0]
        if num_gt == 0:
            return noise, torch.zeros(N, dtype=torch.long, device=device)

        group_ids = self._chromo_group_of_class.to(device=device)
        gt_groups = group_ids[gt_labels]

        matched_gt_idx = torch.zeros(N, dtype=torch.long, device=device)
        offset = 0

        unique_groups, group_counts = torch.unique(gt_groups, return_counts=True)
        num_groups = unique_groups.shape[0]

        # 按组分配 proposal 数 (与 GHSS 相同的比例分配)
        group_info = []
        for gi, grp in enumerate(unique_groups):
            grp_mask = gt_groups == grp
            grp_gt_idx = torch.where(grp_mask)[0]
            K_g = grp_gt_idx.shape[0]

            N_g = max(N * K_g // num_gt, 1)
            if gi == num_groups - 1:
                N_g = N - offset
            N_g = min(N_g, N - offset)
            if N_g <= 0:
                continue

            group_info.append((grp, grp_gt_idx, K_g, N_g, offset))
            offset += N_g

        if not group_info:
            x_start = gt_diffusion[matched_gt_idx]
            return x_start, matched_gt_idx

        # 逐组非平衡 Sinkhorn (组数少, 通常 ≤8, 逐组开销可接受)
        for grp, grp_gt_idx, K_g, N_g, off in group_info:
            grp_noise = noise[off : off + N_g]
            grp_gt = gt_diffusion[grp_gt_idx]
            cost = torch.cdist(grp_noise, grp_gt, p=2)

            # 行边缘: 均匀
            a = torch.ones(N_g, device=device) / N_g
            # 列边缘: 不再强制 proposals_per_gt, 用均匀目标让 OT 自由决定
            b = torch.ones(K_g, device=device) / K_g

            transport = unbalanced_sinkhorn_transport(
                cost,
                epsilon=self.epsilon,
                num_iters=self.num_iters,
                row_mass=a,
                col_mass=b,
                lambda_row=self.lambda_row,
                lambda_col=self.lambda_col,
            )

            row_probs = transport / transport.sum(
                dim=1, keepdim=True
            ).clamp_min(1e-10)
            local_matched = ot_multinomial(row_probs, seed=self.sample_seed)
            matched_gt_idx[off : off + N_g] = grp_gt_idx[local_matched]

        x_start = gt_diffusion[matched_gt_idx]
        return x_start, matched_gt_idx
```

## 4. 实验设计

### 4.1 主实验

| 实验 ID | 耦合策略 | $\lambda_{\text{row}}$ | $\lambda_{\text{col}}$ | $\varepsilon$ | 假设 |
|---------|---------|----------------------|----------------------|---------------|------|
| E1.0 | `ghss` (基线) | ∞ | ∞ | 5.0 | 基线 |
| E1.1 | `unbalanced_ghss` | 1.0 | 1.0 | 5.0 | 非平衡提升 |
| E1.2 | `unbalanced_ghss` | 0.5 | 0.5 | 5.0 | 更松 |
| E1.3 | `unbalanced_ghss` | 2.0 | 2.0 | 5.0 | 接近平衡 |
| E1.4 | `unbalanced_ghss` | 0.1 | ∞ | 5.0 | 仅放松行 |
| E1.5 | `unbalanced_ghss` | ∞ | 0.1 | 5.0 | 仅放松列 |

### 4.2 分层评估

按单图 GT 总数分层评估 recall 和 mAP：

| 分层 | GT 数范围 | 预期收益 |
|------|----------|---------|
| 稀疏 | < 15 | 非平衡优势最显著 |
| 中等 | 15-30 | 中等收益 |
| 密集 | > 30 | 收益较小（接近平衡） |

### 4.3 理论验证指标

1. **边缘违反度**：$\text{KL}(P\mathbf{1} \| a) + \text{KL}(P^\top\mathbf{1} \| b)$，应随 $\lambda$ 减小而增大
2. **传输计划熵**：$H(P)$，应随 $\lambda$ 减小而增大（更分散）
3. **匹配稳定性**：同一图多次耦合的匹配 IoU 方差

### 4.4 消融

- $\varepsilon \in \{1, 5, 10, 20\}$ × $\lambda \in \{0.1, 0.5, 1.0, 2.0, \infty\}$ 网格搜索
- 固定其他超参，仅变 $\lambda$，找拐点

## 5. 预期收益与风险

### 收益

1. **稀疏图提升**：GT 少的图（如部分核型仅 20 条）recall 预期 +2-5%
2. **组间均衡**：小 $K_g$ 组不再过度采样，大 $K_g$ 组不再欠采样
3. **理论优雅**：消除启发式 `proposals_per_gt = max(N_g // K_g, 1)`，由 OT 自然决定

### 风险

1. **$\lambda$ 调参**：过小会导致 OT 退化为纯 Gibbs 分布（$\propto \exp(-C/\varepsilon)$），失去传输意义
2. **收敛性**：非平衡 Sinkhorn 收敛速度略慢于平衡（指数 $<1$），可能需增加 `num_iters`
3. **空组处理**：需明确策略，避免 proposal 浪费

### 退化保护

当 $\lambda_{\text{row}} = \lambda_{\text{col}} = \infty$ 时，`unbalanced_sinkhorn_transport` 应数值等价于 `sinkhorn_transport`。需写单元测试验证此退化情形。
