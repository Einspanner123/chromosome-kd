## 2. 新的唯一主线口径

新增基线配置：

`experiments/configs/ldmdet/a4_dpm_pp_random_chr2024.py`

它保持历史 A4 的数据、增强、RF、AdaLN-Zero、DPM-Solver++、4-step、优化器和
训练时长不变，只用 `_delete_=True` 将 coupling 完整替换为：

```python
coupling=dict(type='random')
```

新增 OCGR 配置：

`experiments/configs/ldmdet/directions/georel/ocgr_random_chr2024.py`

它继承上述干净基线，唯一结构差异为在 cascade heads 4--6 启用零初始化 OCGR。

## 3. 配对与随机性协议

每个训练 seed 的 A4 和 OCGR 必须：

1. 在同一服务器、同型号 GPU 上顺序训练，避免训练硬件混杂；
2. 使用同一命令行 `--seed`，由训练入口写入 `cfg.randomness.seed`；
3. 使用 `--val-seed 42`，逐 epoch 验证前固定推理 RNG，验证后恢复训练 RNG；
4. 使用独立新目录，不续训、不加载历史 StochOT checkpoint；
5. 比较 paired delta，并报告三 seed 均值、标准差和所有原始结果；
6. 最终推理速度统一在 ross GPU 上重新测试。

优先顺序：ross/A6000 完成 seed42 配对，workstation/A5000 完成 seed123 配对，
随后安排 seed789。每台服务器先训练 A4，再训练相同 seed 的 OCGR。

## 5. 论文解释边界

- 历史 RF、DPM++、LQCR、OCGR结果均需明确标注其 coupling 来源；
- 新主线不再把 StochOT 写入模型定义或创新点；
- 新随机耦合基线可能与历史 A4 精度不同，必须先得到新的 A4 结果，不能直接沿用
  历史 `0.746` 作为严格配对基线；
- LQCR需要在干净随机耦合基线 checkpoint 上重新训练或复评后，才能形成完全去除
  StochOT 的最终论文证据链。
