# 染色体检测优化：Phase 2 精细化演进路线图

在 Phase 1 中，我们成功解决了 **“数量一致性”** 与 **“Diffusion 逻辑断层”** 问题。接下来的 Phase 2 将聚焦于 **“极致定位精度”** 与 **“长尾类别（G组/Y）突破”**。

## 主题一：旋转框（OBB）弱监督挖掘与落地

### 1.1 动机与目标

染色体呈长条状且经常倾斜分布，水平框（HBB）在处理重叠目标时会引入大量冗余背景。引入旋转框（OBB）是提升 $mAP\_{75}$ 及以上高精度指标的关键。

### 1.2 核心内容

- **伪旋转框生成 (Pseudo OBB Generation)**：
  - 利用 OpenCV 的 `minAreaRect` 算法，从现有的实例分割掩码（Mask）中提取最小外接矩形。
  - 若仅有 HBB 标注，则通过 LDMDet 的多级 Head 预测角度偏移量 $\\theta$，实现 HBB 到 OBB 的自适应演化。
- **旋转 ROI 对齐 (Rotated ROI Align)**：
  - 将原有的 `RoIAlign` 升级为 `RotatedRoIAlign`，消除旋转目标在特征提取时的几何畸变。
- **旋转一致性约束**：
  - 在一致性 Loss 中引入角度分量，确保同一目标的旋转框在迭代过程中角度预测保持平滑。

## 主题二：小目标与难例（G组/Y染色体）专项增强

### 2.1 动机与目标

目前 G21、G22 及 Y 染色体的精度显著低于平均水平。由于其尺寸极小，在扩散模型的降噪过程中极易丢失细节特征。

### 2.2 核心内容

- **类别感知损失重加权 (Class-Aware Re-weighting)**：
  - 引入 **Equalization Loss** 或 **Dynamic Weighting**，根据验证集上各分类的实时 mAP 表现，动态调高难例类别的分类梯度。
- **局部特征缩放 (Feature Crop & Zoom)**：
  - 针对 Top-K 提案中小于预设阈值的目标，在进入 Head 之前执行局部特征放大操作，补偿扩散过程中的分辨率损失。
- **尺度感知一致性**：
  - 在 $L\_{sop}$ 中引入尺度权重，强制模型对小目标的“存在感”施加更强的监督信号。

## 主题三：跨图像对比学习与细胞级约束

### 3.1 动机与目标

同一细胞内的 46 条染色体不是独立的。它们在染色深度、缩短程度和光照条件下具有全局相关性。

### 3.2 核心内容

- **细胞级对比学习 (Intra-Cell Contrastive Learning)**：
  - 将同一张切片（同一细胞）内的染色体特征映射到统一空间，拉近同类特征，推开异类特征。
- **全局特征归一化**：
  - 引入细胞级的特征统计量（如平均亮度、平均长度），作为 Head 迭代的条件输入（Conditioning），帮助模型适应不同的制片质量。
