## 2. 需要纠正的不准确表述

### 2.1 方向 H: "CFM 消除 exposure bias" — 不准确

**原文** (方向H_FlowMatching检测.md §1.2):
> "训练目标 = 推理用目标, **消除 exposure bias**"

**纠正**: CFM **不能**完全消除 exposure bias。

**理由**:
- 训练时 x_t = (1-t)x_0 + t·x_noise, x_noise 是**真随机噪声**
- 推理时 x_t 来自模型自己的多步采样轨迹 (偏离训练分布)
- 只要推理 > 1 步, exposure bias 就存在

**CFM 的真正优势**:
- 路径更直 (RF 直线 vs DDPM 弯曲随机), 单步近似误差更小
- simulation-free training, 不需 ODE solver 反传
- 训练目标对齐 (v 而非间接反推), 优化更稳定

**真正消除 exposure bias 的是方向 I (Consistency Model)**: CM 的自一致性约束天然让模型在任意 t 上输出一致, 无多步轨迹依赖。

**修正建议**: 方向 H 文档 §1.2 应改为:
> "训练目标与推理用目标对齐 (都预测 v), **减少** (非消除) exposure bias; 真正消除需方向 I 的 CM。"

### 2.2 方向 I: EMA 网络对 4 维框的稳定性

**原文** (方向I_ConsistencyModel检测.md §2.1):
> "EMA 目标网络 (用于一致性约束)"

**潜在问题**: CM 的 EMA 一致性约束在**图像生成**中稳定 (高维平滑流形), 但在 **4 维框**上可能不稳定:
- 4 维框分布稀疏, EMA 网络预测的 x_0 可能抖动很大
- 一致性约束 f(x_t, t) = f(x_{t'}, t') 对 4 维框可能过于严格

**缓解建议**:
1. 用 **soft consistency**: ||f(x_t, t) - f(x_{t'}, t')||² < δ (软约束, 而非严格相等)
2. EMA 动量调高 (如 0.9999 vs 图像的 0.999), 减慢目标网络更新
3. 优先做 **Consistency Distillation (CD)** 而非 CT — 用当前 RF 多步模型作教师, 蒸馏单步学生, 避免从零训练的不稳定

### 2.3 方向 M: 理论收益被高估

**原文** (方向M_ScoreBased检测.md §1.2):
> "DDPM 是 SGM 特例, 换 SGM 不丢已有成果"

**纠正**: 理论上正确, 但**实践收益存疑**:
- 4 维框分布简单, score function 的复杂建模**无优势** (DDPM 已能拟合)
- Langevin 采样需要**更多步数** (通常 100+ 步), 与 mAP_90 瓶颈方向相反 (我们要减少采样步数)
- "支持任意先验"的优势已被方向 F1 的 GMM + DDPM 解决

**修正建议**: 方向 M 应标注为**理论探索**, 不作为短期优先方向。在 README 中明确:
> "方向 M 为理论完备性收录, 实践优先级低于 H/I/N。4 维框任务下 SGM 相比 DDPM 无明显优势。"

### 2.4 方向 N: 与方向 J 的重叠需明确

**当前状况**: 方向 N (端到端可微 Cascade) 与方向 J (确定性 Cascade) 的 J1 子方向 (端到端迭代精化) **核心改动相同** (去 detach)。

**关系澄清**:
- **方向 N**: 保留扩散 t, **仅做最小改动** (去 detach + deep_supervision=False), 验证"采样位置可导"的收益, **1 天可实施**
- **方向 J**: 移除 t, 完整重构 (IoU 递增 + 可学习提议 + 多尺度), **3-8 周工作量**

**建议**: 方向 N 是方向 J 的**前置验证**。如果 N 的 Phase 1 (单行改动) 有收益 → 走 J; 如果无收益 → 说明 detach 不是瓶颈, 跳过 J。

### 2.5 方向 J 的 deep_supervision 与端到端冲突

**原文** (方向J_确定性Cascade精化.md §4.3):
> "每阶段独立计算 loss, 用递增 IoU 阈值"

**问题**: 这与端到端 (J1) **存在目标冲突**:
- deep_supervision: 每个 stage 独立监督 → 梯度只回本 stage
- 端到端: 所有 stage 共同优化最终框 → 梯度贯通

**不能同时做**。两个选择:
1. **端到端 + 只监督最后 stage** (方向 N 的方案): 梯度贯通, 但中间 stage 无直接监督, 收敛慢
2. **deep_supervision + detach** (当前架构): 中间有监督, 但梯度不贯通

**折中方案**: **递减权重的 deep_supervision**
```python
loss_weights = [0.1, 0.2, 0.3, 0.5, 0.8, 1.0]  # 前 stage 低权重, 最后 stage 高权重
# 既保留中间监督 (加速收敛), 又让梯度贯通 (端到端优化)
```

方向 J 文档 §4.3 应补充此冲突说明。

## 3. 优先级修正

### 3.1 原始优先级 (README.md)

```
H (CFM) → I (CM) → J (Cascade) → K/L/M (长期)
```

### 3.2 修正后优先级

基于:
1. **D' 证伪**: 排除"reg head 尺度收缩"假设, 确认瓶颈在 RoI 质量而非 reg head
2. **方向 N 新增**: 单行改动即可验证"采样位置可导"的收益
3. **方向 M 理论收益存疑**: 降级

```
N (端到端最小验证, 1天) → H (CFM, 1-2周) → I (CM, 3-6月) → J (完整 Cascade, 6-12月)
                                                                          │
                                                                          ▼
                                                              K/L (长期创新, 论文级)
                                                                          │
                                                                          ▼
                                                              M (理论探索, 非优先)
```

### 3.3 决策树更新

```
方向 A-F 实验完成
        │
        ▼
方向 N Phase 1 (单行改动, 1天) ──── 收益 > 0.5%? ──── 是 ──→ 走 J (完整 Cascade)
        │                                              │
        否                                             │
        │                                              ▼
        ▼                                         逐步: J1 → J2 → J3
方向 D (BoxRefine) 收益 > 1%? ──── 是 ──→ 走 H (CFM) → I (CM)
        │
        否
        │
        ▼
方向 G (LAMFPN) 收益 > 1%? ──── 是 ──→ 优化特征, 同步尝试 H
        │
        否
        │
        ▼
所有方向 < 0.5% ──── 是 ──→ 果断走 H → I → J
                              │
                              ▼
                          若追求论文创新 → K / L
                          (M 仅理论探索, 非优先)
```

**关键变化**: 新增"方向 N Phase 1"作为**最低成本的验证步骤**, 在投入大方向前先用 1 天确认 detach 是否是瓶颈。

## 4. 各方向核心假设与证伪风险

| 方向 | 核心假设 | 证伪风险 | 验证方式 |
|------|---------|---------|---------|
| **N** | detach 是 RoI 质量瓶颈 | 中 (可能梯度爆炸) | Phase 1 单行改动, 1 天验证 |
| **H** | 训练-推理目标对齐能提精度 | 低 (FlowDet 已验证 +3.6%) | 改 _predict 输出 v, 1-2 周 |
| **I** | 单步生成无累积误差 | 中 (4 维框 EMA 不稳定) | CD 蒸馏优先, 3-6 月 |
| **J** | 确定性精化优于扩散 | 中高 (失去生成灵活性) | N 验证后决定 |
| **K** | 核型结构能消除同组混淆 | 高 (GNN 训练复杂) | 长期研究 |
| **L** | 形态先验能攻分类误差 | 中 (需自监督预训练) | 长期研究 |
| **M** | Score function 优于 DDPM | 高 (4 维无优势) | 理论探索, 非优先 |

**D' 证伪的启示**: 假设可能被推翻。每个方向都应有**快速证伪机制** (如 N 的 Phase 1), 避免长期投入后发现假设错误。

## 5. 推荐组合方案

### 5.1 短期突破 mAP_90 (1-3 月)

**组合**: N (Phase 1-2) + H (CFM)

- N: 去 detach, 梯度贯通, 攻 RoI 采样位置
- H: 改训练目标为 v, 减少多步累积误差
- 两者正交, 可同时做

**预期**: mAP_90 +0.05~0.10

### 5.2 中期彻底换范式 (3-6 月)

**组合**: I (Consistency Model) + N 的经验

- 用 N 的经验确认"端到端有效"
- I 实现单步生成, 消除累积误差
- 保留 N 的梯度贯通思想

**预期**: mAP_90 +0.10~0.15, 推理加速 4-8x

### 5.3 长期论文创新 (6-12 月)

**组合**: K (核型结构化) + L (形态先验)

- K: 攻同组混淆 (43.4% 分类误差)
- L: 显式注入形态学先验
- 两者可组合 (GNN + 形态编码器)

**预期**: 分类误差 -20%, 论文级创新
