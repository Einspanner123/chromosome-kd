# 实证推理优化方案

> **基于实测数据**的 LDMDet 推理加速方案，取代原 IO1-IO5 理论假设。
>
> **实测基线**: RF + Heun 4步 (7 NFE) × 6 级联头 × 500 proposals = 42 次单头前向
>
> **实测延迟**: 335 ms/图 (Backbone 26ms + 采样循环 309ms)
>
> **验证数据**: [benchmark_report.json](../../../work_dirs/inference_opt/benchmark_report.json)
>
> **SOTA checkpoint**: `work_dirs/reproduce_0751_stochot_eps5_v2/best_coco_bbox_mAP_epoch_59.pth` (mAP=0.753)

---

> ⚠️ **暂时废弃**：以下瓶颈实测数据（335 ms/图、RoIAlign 3.53ms/52.2%、DynamicConv 2.54ms/37.5%、N-Scaling 延迟、各方向绝对延迟数值等）基于旧数据集 Chromosome20240904 的 checkpoint（mAP≈0.753），24obj 数据集上的推理优化结论待验证。
>
> 注：优化方向 A-F 的理论分析（计算复杂度 O(N·P²) 等、跨步/跨头正交性、加速比推导、组合策略预估）为架构层面，与数据集无关，保留有效；各方向中引用的绝对延迟数值与 SOTA checkpoint mAP=0.753 均为旧数据集产物，后续需在 24obj checkpoint 上重测。

## 1. 实测瓶颈分解

### 1.1 组件级延迟 (单次 single_head 调用)

| 组件 | 均值 (ms) | 占比 | 复杂度 | 可优化性 |
|------|:---:|:---:|:---:|:---:|
| **RoIAlign** | **3.53** | **52.2%** | O(N·P²) | 需重训 (架构参数) |
| **DynamicConv** | **2.54** | **37.5%** | O(N·P²·d) | 需重训 (架构参数) |
| Self-Attn | 0.15 | 2.2% | O(N²·d) | 已用 SDPA, 无优化空间 |
| reg_head | 0.11 | 1.6% | O(N·d) | - |
| FFN | 0.07 | 1.0% | O(N·d²) | - |
| cls_head | 0.04 | 0.6% | O(N·d) | - |

**关键发现**: Self-Attn 仅占 2.2%，原 IO1-IO5 方向假设的 "N² attention 瓶颈" 不成立。真正瓶颈是 RoIAlign + DynamicConv (89.7%)，二者均为 O(N·P²)，与 N 线性相关（非 N²）。

### 1.2 N-Scaling 实测

| N | 延迟 (ms) | 加速比 | 注意：Self-Attn 理论加速 |
|---|:---:|:---:|:---:|
| 500 | 303.9 | 1.00x | 1.0x |
| 300 | 226.0 | 1.35x | 2.8x |
| 200 | 201.2 | 1.51x | 6.2x |
| 100 | 166.7 | 1.82x | 25.0x |
| 50 | 153.8 | 1.98x | 100.0x |

**结论**: N 从 500 减到 50 仅 2x 加速（非 N² 的 100x），因 Self-Attn 仅占 2.2%，主瓶颈 O(N) 的 RoIAlign/DynamicConv 仅线性受益。

### 1.3 原 IO1-IO5 判定

| 方向 | 判定 | 证据 |
|------|:---:|------|
| IO1 自适应步数终止 | **证伪** | x0_Δrel 最低 0.166 (>>阈值 0.01), cls 一致率仅 65% |
| IO2 投机 Draft-Verify | **证伪** | 同 IO1, 早期步 cls 一致率 57%, draft 不可靠 |
| IO3 Top-K 框剪枝 | **弱支持** | N=100 仅 1.82x (非 25x), 且有精度风险 |
| IO4 级联头提前退出 | **部分可行** | Head 4→5, 5→6 box_Δrel < 0.008, 但 cls 一致率 88% |
| IO5 跨步 RoI 缓存 | **证伪** | 框位移 93-124px/步, RoI 特征剧变 |

## 2. 新优化方向

按 "是否需重训" 分两类：

### 立即可验证 (推理修改, 无需重训)

| 方向 | 核心思想 | 预期加速 | 精度风险 |
|------|---------|:---:|:---:|
| **A: 级联头跳过** | 推理时跳过末 1-2 个级联头 | 1.17-1.33x | 中 (cls 一致率 88%) |
| **B: DPM-Solver++ 切换** | Heun (7 NFE) → DPM++ (4 NFE) | 1.75x | 低-中 |
| **C: Proposal 剪枝** | 第 1 步后按 score 截断到 top-K | 1.2-1.5x | 低 |
| **D: 步数减少** | 4 步 → 3 步 | 1.4x | 中 |

| 方向 | 核心思想 | 预期加速 | 精度风险 |
|------|---------|:---:|:---:|
| **E: RoIAlign 瘦身** | output_size 7→5, sampling_ratio 2→0 | 1.3-1.5x | 中 |
| **F: DynamicConv 瘦身** | dynamic_dim 64→32 | 1.2-1.3x | 中 |

## 方向 A: 级联头跳过

### 实证依据

级联头间预测差异实测 (30 张图, 4 步 × 6 头):

| 头对 | box_Δrel (step 3) | cls 一致率 | 判定 |
|------|:---:|:---:|:---:|
| 1→2 | 0.0174 | 72.1% | 大幅修正, 不可跳 |
| 2→3 | 0.0061 | 87.1% | 中等修正, 不可跳 |
| 3→4 | 0.0140 | 88.8% | 仍有修正, 不可跳 |
| 4→5 | 0.0037 | 87.6% | **微小修正, 可跳** |
| 5→6 | 0.0032 | 86.3% | **微小修正, 可跳** |

Head 4→5 和 5→6 的 box 相对变化 < 0.004，但 cls 一致率 ~88% 意味着 12% 的 proposal 标签会改变。

### 具体实现

修改 [head.py](../../../ldmdet/core/head.py) 的 `predict()` 方法:

```python
@torch.no_grad()
def predict(self, features, img_metas, rescale=True, return_trajectory=False,
            skip_last_heads=0):  # 新增参数
    # ... 原有初始化 ...
    
    effective_heads = self.head_series[:self.num_heads - skip_last_heads]
    
    for step_idx, (t_curr, t_next) in enumerate(time_pairs):
        cls_logits, pred_bboxes, x0_raw = self._forward_at_t(
            features, x_raw, t_curr, img_metas, 
            heads=effective_heads  # 传入子集
        )
        # ... 原有采样逻辑 ...
```

修改 `_forward_at_t` 支持指定 head 子集:

```python
def _forward_at_t(self, features, x_raw, t, img_metas, heads=None):
    heads = heads if heads is not None else self.head_series
    # ... 原 forward 逻辑, 遍历 heads 而非 self.head_series ...
```

### 配置

```python
# 推理时通过 test_cfg 传入
test_cfg = dict(
    use_nms=True,
    score_thr=0.5,
    skip_last_heads=1,  # 跳过最后 1 个头 (保守)
)
```

### 预期收益

| skip_last | 有效头数 | 单头前向 | 采样加速 | 总加速 |
|:---:|:---:|:---:|:---:|:---:|
| 0 (基线) | 6 | 42 | 1.00x | 1.00x |
| 1 | 5 | 35 | 1.20x | 1.17x |
| 2 | 4 | 28 | 1.50x | 1.33x |

### 精度风险

- **skip=1**: 12% proposal 标签变化, 预期 mAP 降 0.001-0.003
- **skip=2**: 更激进, 预期 mAP 降 0.003-0.008
- **缓解**: 仅在后期步 (step ≥ 2, t < 0.8) 跳过, 早期步保留全部头

## 方向 B: DPM-Solver++ 切换

### 实证依据

当前 Heun 4 步 = 7 NFE (最后一步 t_next=0 退化为 Euler)。DPM-Solver++ 每步仅 1 NFE, 利用 x0 历史做多项式插值, 已在 [rectified_flow.py](../../../ldmdet/diffusion/rectified_flow.py#L83) 实现。

| 求解器 | 步数 | NFE | 单头前向 | vs 基线 |
|--------|:---:|:---:|:---:|:---:|
| Heun (当前) | 4 | 7 | 42 | 1.00x |
| DPM-Solver++ (order 2) | 4 | 4 | 24 | **1.75x** |
| DPM-Solver++ (order 2) | 3 | 3 | 18 | **2.33x** |
| DPM-Solver++ (order 3) | 4 | 4 | 24 | 1.75x |

### 具体实现

**纯配置修改, 零代码改动**:

```python
# experiments/configs/ldmdet/inference_opt/b_dpm_solver.py
_base_ = ['../ldmdet_rf_heun_adaln_stochot_eps5.py']

model = dict(
    bbox_head=dict(
        solver_type='dpm_solver_pp',  # 'heun' → 'dpm_solver_pp'
        sampling_timesteps=4,          # 保持 4 步
    ),
)
```

3 步版本:

```python
model = dict(
    bbox_head=dict(
        solver_type='dpm_solver_pp',
        sampling_timesteps=3,  # 减少到 3 步
    ),
)
```

### 精度风险

- **DPM++ 4 步**: 1 NFE/步, 无 Heun 第 2 NFE 的修正, 预期 mAP 降 0-0.003
- **DPM++ 3 步**: 更激进, x0_Δrel=0.166 说明 3 步可能不够, 预期 mAP 降 0.003-0.010
- **优势**: DPM-Solver++ 的多项式插值在少步数时优于 Euler, 是少步采样的最优选择

## 方向 C: Proposal 剪枝

### 实证依据

每步高置信度 proposal 占比:

| Step | t_curr | hi_conf (>0.5) | med_conf (>0.2) | top-100 均分 |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 1.000 | 38.7% | - | - |
| 1 | 0.900 | 46.0% | - | - |
| 2 | 0.750 | 47.8% | - | - |
| 3 | 0.500 | 47.2% | - | - |

约 47% 的 proposal 高置信, 剩余 53% 为低置信噪声框。但 box_renewal 已将 score < score_thr 的框替换为噪声, 实际有效框数动态变化。

N-Scaling 延迟实测:

| N | 延迟 (ms) | 加速比 |
|---|:---:|:---:|
| 500 | 303.9 | 1.00x |
| 300 | 226.0 | 1.35x |
| 200 | 201.2 | 1.51x |
| 100 | 166.7 | 1.82x |

### 具体实现

在 `predict()` 的步间循环中, 第 1 步后按 score 截断:

```python
@torch.no_grad()
def predict(self, features, img_metas, rescale=True, return_trajectory=False,
            prune_after_step=1, prune_to_n=300):  # 新增参数
    # ...
    for step_idx, (t_curr, t_next) in enumerate(time_pairs):
        cls_logits, pred_bboxes, x0_raw = self._forward_at_t(
            features, x_raw, t_curr, img_metas
        )
        
        # === Proposal 剪枝 ===
        if step_idx == prune_after_step and prune_to_n < self.num_proposals:
            scores = torch.sigmoid(cls_logits).max(-1)[0]  # [bs, N]
            for i in range(len(img_metas)):
                _, topk_idx = scores[i].topk(prune_to_n)
                x_raw[i] = x_raw[i, topk_idx]
            # 更新 num_proposals 供后续步使用
            effective_n = prune_to_n
        # ...
```

**注意**: 剪枝后 x_raw 的 N 减小, 后续步的 RoIAlign/DynamicConv/Self-Attn 均受益。但 `_forward_at_t` 内部的 `head.forward()` 需要适配可变 N (当前已支持, 因 bboxes 维度动态)。

### 配置

```python
test_cfg = dict(
    use_nms=True,
    score_thr=0.5,
    prune_after_step=1,   # 第 1 步后剪枝
    prune_to_n=300,       # 保留 top-300
)
```

### 预期收益

| prune_to_n | 后 3 步加速 | 总加速 (7 NFE) | mAP 风险 |
|:---:|:---:|:---:|:---:|
| 500 (基线) | 1.00x | 1.00x | - |
| 300 | 1.35x | 1.23x | 低 |
| 200 | 1.51x | 1.30x | 低-中 |
| 100 | 1.82x | 1.43x | 中 |

### 精度风险

- **N=300**: 保留 60% proposal, 染色体 GT 约 46 个, 冗余仍足够, 预期 mAP 降 < 0.001
- **N=100**: 保留 20%, GT 46 个, 冗余 2x, 预期 mAP 降 0.001-0.005
- **风险点**: 低置信但真实的框 (如遮挡染色体) 可能被误剪

## 方向 E: RoIAlign 瘦身 (需重训)

### 实证依据

RoIAlign 占单头 52.2% (3.53ms), 是第一瓶颈。当前 `output_size=7, sampling_ratio=2`。

复杂度: `N × output_size² × channels × sampling_ratio²`

| 参数 | 当前 | 优化 | RoIAlign 降幅 |
|------|:---:|:---:|:---:|
| output_size | 7 | 5 | 49→25, 降 49% |
| sampling_ratio | 2 | 0 (auto) | 通常 1, 降 75% |
| 二者叠加 | - | - | 降 ~70% |

### 具体实现

修改配置 (需重训):

```python
# experiments/configs/ldmdet/inference_opt/e_roi_slim.py
_base_ = ['../ldmdet_rf_heun_adaln_stochot_eps5.py']

model = dict(
    bbox_head=dict(
        single_head=dict(
            pooler_resolution=5,  # 7 → 5
        ),
        roi_extractor=dict(
            roi_layer=dict(
                output_size=5,        # 7 → 5
                sampling_ratio=0,     # 2 → 0 (auto)
            ),
        ),
    ),
)
```

### 预期收益

| 配置 | RoIAlign (ms) | 单头 (ms) | 采样加速 |
|------|:---:|:---:|:---:|
| 7×7, sr=2 (基线) | 3.53 | 6.77 | 1.00x |
| 5×5, sr=0 | ~1.50 | 4.74 | **1.43x** |
| 3×3, sr=0 | ~0.70 | 3.94 | 1.72x (精度风险高) |

**附加收益**: DynamicConv 的 `out_layer` 输入维度从 `256×49=12544` 降到 `256×25=6400`, DynamicConv 也加速 ~40%。

### 精度风险

- **5×5**: 中等风险, 染色体框较大 (平均 50×150 px), 5×5 特征图仍保留足够空间信息, 预期 mAP 降 0-0.003
- **3×3**: 高风险, 小染色体可能丢失空间细节, 不推荐

## 方向 F: DynamicConv 瘦身 (需重训)

### 实证依据

DynamicConv 占单头 37.5% (2.54ms)。当前 `dynamic_dim=64, dynamic_num=2`。

核心计算:
- `dynamic_layer`: Linear(256, 2×256×64=32768) — 生成动态卷积参数
- `bmm 1`: (N, 49, 256) × (N, 256, 64) — 特征降维
- `bmm 2`: (N, 49, 64) × (N, 64, 256) — 特征升维
- `out_layer`: Linear(256×49=12544, 256) — 展平后投影

`dynamic_dim` 从 64 降到 32: bmm 计算量减半, dynamic_layer 输出维度减半。

### 具体实现

```python
# experiments/configs/ldmdet/inference_opt/f_dyn_slim.py
_base_ = ['../ldmdet_rf_heun_adaln_stochot_eps5.py']

model = dict(
    bbox_head=dict(
        single_head=dict(
            dynamic_dim=32,  # 64 → 32
        ),
    ),
)
```

### 预期收益

| 配置 | DynamicConv (ms) | 单头 (ms) | 采样加速 |
|------|:---:|:---:|:---:|
| dim=64 (基线) | 2.54 | 6.77 | 1.00x |
| dim=32 | ~1.40 | 5.63 | 1.20x |
| dim=16 | ~0.80 | 5.03 | 1.35x (精度风险高) |

### 精度风险

- **dim=32**: 中等风险, 交互能力减半, 预期 mAP 降 0.001-0.005
- **dim=16**: 高风险, 不推荐

## 3. 组合策略

### 推荐实施顺序

```
阶段 1: 立即验证 (无需重训)
  ├─ B: DPM-Solver++ 4 步  → 1.75x (纯配置, 零代码)
  ├─ C: Proposal 剪枝 N=300 → 1.23x (代码修改小)
  └─ A: 跳过末 1 头        → 1.17x (代码修改小)

阶段 2: 组合验证 (无需重训)
  └─ B+C+A 叠加            → 预期 2.0-2.5x

阶段 3: 重训实验 (需新训练)
  ├─ E: RoIAlign 5×5       → +1.43x
  └─ F: DynamicConv dim=32 → +1.20x
```

### 组合收益预估

| 组合 | NFE | 有效头 | N | 单头前向 | 预期加速 | mAP 预期 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 基线 | 7 | 6 | 500 | 42 | 1.00x | 0.753 |
| B (DPM++4) | 4 | 6 | 500 | 24 | 1.75x | ~0.750 |
| B+C (N=300) | 4 | 6 | 300 | 24* | 2.0x | ~0.749 |
| B+C+A (skip1) | 4 | 5 | 300 | 20* | 2.3x | ~0.747 |
| B+C+A+E+F (重训) | 4 | 5 | 300 | 20* | **3.0x** | ~0.745 |

*注: 剪枝后后续步 N 减小, 实际加速更高

### 正交性

```
总延迟 ≈ Backbone + NFE × H × (RoIAlign(N,P) + DynamicConv(N,P,d) + SelfAttn(N) + FFN)
                ↑B     ↑A    ↑C              ↑E(P)              ↑F(d)
```

- **B × A**: 完全正交 (NFE × 头数)
- **B × C**: 完全正交 (NFE × N)
- **A × C**: 完全正交 (头数 × N)
- **E × F**: 部分正交 (P 和 d 独立, 但都在 DynamicConv 内)
- **推理优化 (A/B/C/D) × 架构优化 (E/F)**: 完全正交
