# LDMDet 精度瓶颈重新审视（2026-08-08）

## 结论先行

当前最主要的精度瓶颈已经不是 RF solver 的数值阶数、框合法性或“所有样本都需要更多采样步”。现有证据更支持：

1. **高 IoU 下的细粒度回归与类别排序**是总体 mAP 的主要剩余空间；AP50 已约 0.989、AP75 约 0.972–0.973，但跨 IoU 阈值平均 mAP 仅约 0.861，损失集中在更严格阈值及排序质量。
2. **小目标与尾部相似类别**是最不稳定部分。G21/G22/Y 的类别 AP 约 0.77–0.79，明显低于 A/B 类约 0.90；APs 在相邻 epoch/随机种子间可从约 0.50 波动到 0.56。
3. **RoI 外观表征，尤其形态、方向和着丝粒线索不足**，比继续修改扩散轨迹更值得优先投入。7×7 RoI 空间结构一旦破坏，mAP 从 0.863 跌至 0.009，说明结构性空间信息是不可替代主通路。
4. 密集/重叠场景仍是合理候选瓶颈，但目前缺少按遮挡或 GT 重叠度分层的直接 AP 证据，不能先验宣称它是第一瓶颈。

## 1. 已基本排除的方向

### 1.1 “solver 步数不够”不是总体 mAP 主因

修复非 ensemble 输出错误后，固定 2 步与动态 1/2 步的 mAP 均为 0.857–0.858，约三分之一图像可以只做 1 步且不降低 mAP。这说明易样本上的第二步存在冗余；困难样本的第二步主要保护 APs，而非普遍提高总 mAP。

证据：`work_dirs/diagnosis/gacs_box_scale_calibration.json`、`gacs_final_seed42_repeat.json`、`gacs_seed0.json`、`gacs_seed1.json`。

### 1.2 非法框流形不是当前精度上限

BoxChart 消除了中心越界、负宽高和 gap simplex 非法状态，并改善了数学一致性；但 BoxChart/MCCR 的已有 step sweep 没有产生稳定 mAP 增益。因此它是训练稳定性和理论闭合的重要基础，不是当前数据上独立的精度突破。

证据：`work_dirs/diagnosis/box_space_boxchart_a4_init_100.json`、`box_space_boxchart_low_lr_best_100.json`、`boxchart_low_lr_step_sweep.json`、`mccr_projection_only_step_sweep.json`。

### 1.3 简单增加时间条件或注意力复杂度优先级低

AdaLN 调制幅度是活跃的（既有诊断中 $\alpha$ 约 0.47–0.81），但相比 scale-shift 未形成 mAP 增益。级联注意力在中间头趋于集中、首头接近均匀且随后非单调；Self-Attention 计算占比也很低。当前证据不支持把“更强全局 attention”列为第一实验。

来源：`docs/research/STRUCTURAL_IMPROVEMENT_ANALYSIS.md`、`work_dirs/diagnosis/structural_diagnosis.json`、`structural_diagnosis_v2.json`。

## 2. 正向证据：瓶颈具体在哪里

### 2.1 指标形状指向高阈值质量，而不是粗召回

在 A4 DPM++ 训练后期，代表性验证结果为 mAP 0.861、AP50 0.989、AP75 0.972–0.973。AP50 几乎饱和，说明“是否找到了正确对象”的粗召回不是主要问题；mAP 比 AP75 仍低约 0.11，则严格 IoU 阈值下的框精修、置信度排序和细粒度分类仍有显著空间。

来源：`work_dirs/a4_dpm_pp_24obj/20260708_000414/20260708_000414.log`（例如 epoch 129、143、146）。

注意：仅由 COCO 汇总指标无法严格分离分类、定位、重复框和漏检，下一阶段必须做 oracle/TIDE 式分解。

### 2.2 尾部类别呈现“低 AP、但 AP50 很高”

同一日志的 epoch 129：G21/G22/Y 的 AP 分别约 0.788/0.784/0.771，但 AP50 约 0.989/0.985/0.972，AP75 约 0.947/0.935/0.922。它们并非大量完全漏检，而是在严格定位、相似类别排序或小目标稳定性上丢分。A1–B5 的 AP 约 0.90，差距具有明确的类别/尺度结构。

此外，既有统计显示类间 log-area 均值范围约 2.045、标准差约 0.589，尺度与类别高度相关；Y 训练样本约 397，而多数类别约 1500–1600。Y 与 G21 等相近尺度类别仍需形态/着丝粒特征，单纯增加尺度编码容易学习类别先验而非可泛化判据。

来源：同上日志；汇总诊断见 `docs/research/STRUCTURAL_IMPROVEMENT_ANALYSIS.md`。

### 2.3 7×7 RoI 空间路径是精度命门

D1 消融将 RoI 空间结构破坏后，mAP 从 0.863 降至 0.009。这不是“小幅有益”，而是说明当前检测头高度依赖局部空间布局。任何形态创新都应作为并行、零初始化残差增强，不能替换现有 RoIAlign→DynamicConv 路径。

来源：`experiments/analysis/d1_roi_ablation.py`、`work_dirs/diagnosis/d1_roi_ablation.json`。

### 2.4 级联头不是简单重复，但末端存在样本条件冗余

既有诊断中各头回归更新标准差不同（约 head0 0.936、head3 1.093、head5 0.450），表明各级承担不同精炼角色。GACS 同时证明约三分之一易样本的末端 solver 计算可省。因此更合适的优化不是统一删头，而是让后期头专门处理高 IoU 精修与困难类别。

## 3. 建议的下一轮诊断：先把上限拆开

按优先级执行，所有比较固定 checkpoint、proposal 初始随机种子和评估顺序：

1. **Oracle 误差分解**：分别替换为 GT 类别、GT 匹配框，测出 classification oracle、localization oracle、duplicate removal 和 missed-GT 的 mAP 上限；按 small/medium/large 及类别报告。
2. **IoU 阈值剖面**：输出 AP50:5:95，而不只 AP50/AP75；若增益只发生在 AP85–95，明确归因于精修。
3. **proposal recall 与 head-wise AP**：记录每个 solver 步、每个 cascade head 的 recall@IoU 和 oracle AP，定位“小目标在 proposal 阶段丢失”还是“后期分类/回归未收敛”。
4. **重叠度分层**：按每个 GT 与其他 GT 的最大 IoU、中心距离/尺度比划分非重叠、邻近、重叠组，分别报告漏检、重复框和 AP。
5. **G21/G22/Y 混淆审计**：用 GT 匹配后的分类矩阵区分相互混淆、背景漏检和框不准；同时报告样本数与 bootstrap 置信区间。

在完成上述分解前，任何 0.001–0.003 mAP 变化都只视为候选信号，不视为创新成立。GACS 的 APs 在 seed 1 为 0.500、seed 0/42 约 0.556，也说明小目标总体样本量有限、方差很大。

## 4. 最值得验证的结构创新

### P1：末级形态感知 RoI 残差分支（首选）

仅在最后 2–3 个 cascade heads 增加轻量并行分支，从 7×7 RoI 特征显式提取二阶矩/主方向、长轴投影序列、边缘轮廓及可学习的着丝粒位置；经零初始化门控后加到现有 proposal feature，而不替换 DynamicConv。

理论上，尺度和长宽比不足以区分等尺度染色体；沿主轴的带型/轮廓是条件互信息 $I(Y;M\mid S)$ 的来源。若新增形态变量 $M$ 在给定尺度 $S$ 后仍降低类别条件熵，即 $H(Y\mid S,M)<H(Y\mid S)$，它才提供真实新信息，而非重复尺度先验。

通过门槛：三随机种子平均 mAP 至少 +0.003，且 G21/G22/Y 平均 AP 与 AP85–95 同向提升；参数/延迟增幅需报告。若只提高训练集或只改善 AP50，则证伪。

### P2：晚期高 IoU 专职回归头

保持前级匹配/召回，最后两头改用更高 IoU 质量权重或显式 IoU-quality calibration，使分类分数近似 $P(c\mid x)\cdot \widehat{IoU}^{\beta}$；同时对 BoxChart 坐标采用尺度归一化的高阈值损失。目标是直接改善 COCO 排序与 AP85–95。

通过门槛：AP75 不退、AP85–95 显著提升，分类 oracle 与定位 oracle 的差距按预期收窄。若只改变置信度但 oracle localization 不变且 mAP无提升，则停止。

### P3：小目标/尾类的匹配与 proposal 保真

若 head-wise recall 证明 G21/G22/Y 在早期 proposal 阶段已丢失，再引入尺度感知匹配成本、尾类均衡采样或小框的第二步强制保留；不要在证据不足时直接做类别重加权，因为其 AP50 已很高，可能损害总体排序。

### P4：重叠关系精炼（条件方向）

只有在重叠分层审计证明误差随 GT 重叠度显著上升时，再在末级加入 proposal-pair 几何关系/互斥分配模块。现有 attention 诊断不足以支持直接堆叠更重的 Transformer。

## 5. 研究决策

- GACS 保留为推理效率贡献，论文表述限定为“约 33% 样本 1 步退出、mAP 无可测损失”，不声称增精度。
- 下一项工程工作应先完成 oracle + head-wise + overlap 三类诊断；它们决定 P1/P2/P3/P4 的优先级。
- 依据当前证据，独立精度创新首选 **P1 末级形态感知 RoI 残差分支**，通用化表述为细长/小目标的规范化形态表征；染色体着丝粒只是该结构在领域数据上的一个实例。
