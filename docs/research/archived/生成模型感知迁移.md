# 方向六：生成模型感知迁移

> **创建时间**：2026-06-28
> **状态**：Phase 1 E6.3 enhanced 训练进行中 (2026-06-29)
> **基线**：方向一~五 SOTA mAP=0.753

## 1. 方向概述

### 1.1 核心思想
将 ChromoGen 生成模型（UNet 编码器）的染色体领域感知特征迁移到 LDMDet 检测器，
通过 Feature Bridge Module (FBM) 将生成特征投影并融合到 LDMDet FPN 特征空间。

### 1.2 动机
- 方向一~五的瓶颈在于**特征来源**（ResNet-50 ImageNet 预训练），缺乏染色体领域知识
- ChromoGen UNet 在染色体生成任务上训练，包含染色体结构理解（带型模式、着丝粒位置、臂比）
- 生成模型特征与判别模型特征正交，可叠加使用

### 1.3 与其他方向的关系
- **正交性**：方向六不改变耦合策略、轨迹、匹配机制，仅增强特征来源
- **可叠加性**：可与方向一~五任意组合
- **突破潜力**：直击特征瓶颈，理论上有望突破 0.753 上限

## 2. 架构设计

### 2.1 特征维度对齐方案

| LDMDet FPN Level | Stride | 通道 | ChromoGen UNet | 通道 | 融合方式 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| Level 0 | 4 | 256 | — | — | 不融合 (无对应) |
| Level 1 | 8 | 256 | down1 | 320 | 1×1 conv 投影 + alpha 加权 |
| Level 2 | 16 | 256 | down2 | 640 | 1×1 conv 投影 + alpha 加权 |
| Level 3 | 32 | 256 | down3 + mid | 1280+1280 | 1×1 conv 投影 + mid 上采样 + alpha 加权 |

### 2.2 FeatureBridgeModule (FBM)

```python
class FeatureBridgeModule(nn.Module):
    def __init__(self, cg_channels=[320, 640, 1280, 1280], ld_channels=256):
        # 4 个 1×1 conv 投影层 (ChromoGen 通道 → LDMDet 通道)
        # 3 个可学习融合权重 alpha (零初始化, 保证训练初始不破坏 baseline)
        self.alpha = nn.Parameter(torch.zeros(3))  # level 1/2/3

    def forward(self, ld_feats, cg_feats):
        fused = list(ld_feats)  # level 0 保持不变
        fused[1] = ld_feats[1] + self.alpha[0] * proj(cg_feats['down1'])
        fused[2] = ld_feats[2] + self.alpha[1] * proj(cg_feats['down2'])
        fused[3] = ld_feats[3] + self.alpha[2] * (proj(cg_feats['down3']) + upsample(proj(cg_feats['mid'])))
        return fused
```

**关键设计**：
- **零初始化**：alpha=0 保证训练初始 FBM 输出 = LDMDet baseline，无回归风险
- **渐进激活**：alpha 可学习，训练过程中逐步吸收 ChromoGen 特征
- **Level 0 不融合**：stride 4 无对应 ChromoGen 特征（UNet 在 H/8 latent 空间操作）

### 2.3 ChromoGenFeatureExtractor

```python
class ChromoGenFeatureExtractor(nn.Module):
    def __init__(self, unet, config=UNetFeatureConfig()):
        # 冻结 UNet, 注册 forward hook 收集 down_blocks/mid_block 特征
        self.set_frozen()  # eval + requires_grad=False

    def forward(self, latent, timestep, encoder_hidden_states):
        with torch.no_grad():
            _ = self.unet(latent, timestep, encoder_hidden_states)
        # 通过 hook 收集的特征
        return self._feature_buffer
```

**Hook 机制**：
- 兼容 diffusers UNet2DConditionModel（down_blocks/mid_block）
- 兼容 MockUNet（测试用，通过 _feature_cache 属性）
- no_grad 节省显存，冻结参数避免影响 ChromoGen

#### Phase 0 实验结果 (2026-06-28)

##### 5.0.1 Linear Probe 实验

**实验设置**：
- 模型：ChromoGen Phase1 (100 epochs, image-only)
- 特征提取：固定 timestep=500, 无条件 (zero embedding)
- ROI 特征：对每个 bbox 用 ROI Align 提取 7×7 特征
- 训练数据：300 张训练图 (14031 bbox), 75 张验证图 (3497 bbox)
- 分类器：线性层 (in_channels×7×7 → 24 类), Adam lr=1e-3, 80 epochs
- 随机基线：1/24 ≈ 4.2%

**结果** ([probe_results_full.json](file:///home/linkst/workplace/chromo/chromosome-kd/work_dirs/chromogen_phase1/probe_results_full.json))：

| 层 | 通道数 | 验证准确率 | vs 随机基线 |
|:---:|:---:|:---:|:---:|
| vae_latent | 4 | **17.8%** | 4.2× |
| down1 | 320 | **22.8%** | 5.4× |
| down2 | 640 | 19.2% | 4.6× |
| down3 | 1280 | 10.8% | 2.6× |
| mid | 1280 | 10.0% | 2.4× |

**关键发现**：
1. ✅ **所有层均显著高于随机基线 (4.2%)**，证明 ChromoGen 特征确实包含检测信息
2. 🏆 **down1 (浅层) 表现最佳 (22.8%)**，比随机高 5.4 倍，浅层保留了更多空间/纹理信息
3. 📉 **深层 (down3, mid) 表现较差 (~10%)**，深层特征偏向生成任务，丢失了分类信息
4. 💡 **vae_latent (4ch) 达到 17.8%**，压缩表示仍含丰富信息

**结论**：ChromoGen 特征具有迁移价值，**down1 层应作为 FBM 融合的重点**。

##### 5.0.2 CKA 相似度分析

**实验设置**：
- 对比模型：ImageNet 预训练 ResNet50 (作为检测特征参考)
- 图像数：100 张
- 特征池化：自适应平均池化到 1×1 后展平
- CKA 方法：线性 CKA + 200 次置换检验

**结果** ([cka_results.json](file:///home/linkst/workplace/chromo/chromosome-kd/work_dirs/chromogen_phase1/cka_results.json))：

| ChromoGen \ ResNet | layer1 (H/4) | layer2 (H/8) | layer3 (H/16) | layer4 (H/32) |
|:---:|:---:|:---:|:---:|:---:|
| vae_latent | 0.134 | 0.089 | 0.123 | 0.105 |
| down1 | 0.650 | 0.627 | **0.678** | 0.626 |
| down2 | 0.735 | 0.700 | **0.783** | 0.735 |
| down3 | 0.655 | 0.664 | **0.786** | 0.764 |
| mid | 0.623 | 0.635 | **0.760** | 0.742 |

**关键发现**：
1. ✅ **所有 CKA 值均显著 (p=0.005 < 0.05)**，ChromoGen 特征与标准视觉特征有真实相似性
2. 🎯 **最佳匹配均为 ResNet layer3**，说明 ChromoGen 特征与 ResNet 深层语义特征最相似
3. 📊 **down2/down3 与 ResNet layer3 CKA 最高 (~0.78)**，中层特征语义对齐最好
4. 🔍 **vae_latent 与所有 ResNet 层 CKA 低 (~0.1)**，VAE 潜空间是异构压缩表示
5. 💡 **ChromoGen 特征不是 ResNet 的简单复制** (CKA < 0.8)，含有正交补充信息

**结论**：ChromoGen 特征与 ResNet 特征既相似又正交，**适合作为检测特征的补充**，支持方向六的核心假设。

##### E6.3 enhanced 训练 🔄 (进行中)

**配置**: [experiments/configs/ldmdet/gen_transfer_phase1_e6_3_enhanced.py](file:///home/linkst/workplace/chromo/chromosome-kd/experiments/configs/ldmdet/gen_transfer_phase1_e6_3_enhanced.py)

**针对 E6.2 失效的改进**:

1. **FBM 架构增强**:
   - per-channel sigmoid gate (替代标量 alpha): 每通道独立门控, 表达力更强
   - gate_init=0.1 (替代零初始化): 初始 10% 融合权重, 提供非零梯度信号
   - 投影后加 GroupNorm + GELU: 增强特征对齐能力
   - residual gating: `fused = ld*(1-g) + g*cg_proj`, 保证 baseline 路径不被破坏

2. **ChromoGen UNet 部分解冻** (freeze_last_n_blocks=1):
   - 解冻 down_blocks[-1] (DownBlock2D, 1280ch) + mid_block
   - 让特征适应检测任务 (E6.2 全冻结导致 domain gap 无法弥补)
   - gradient checkpointing 节省显存

3. **诊断插桩** (FeatureBridgeDiagnosticsHook):
   - 每 50 iter 记录 gate 值/特征范数/proj 参数/gate 梯度/UNet 梯度
   - 便于定位哪个模块在贡献/拖累
   - SwanLab 中 `fbm/` 命名空间下查看

**优化器分组**:
- FBM (gate + proj): 10x lr (加速收敛)
- 解冻的 UNet block: 0.1x lr (预训练参数, 小 lr 微调)
- 其他: baseline lr

**训练状态** (Epoch 1, iter 350/770):
- loss: 79.6 → 63.3 (初始偏高因 gate_init=0.1 注入未适应的 CG 特征, 持续下降)
- grad_norm: 209809 → 73458 (偏高但有 clip_grad=1.0, 持续下降)
- 显存: ~13 GB (比 E6.2 多 2GB, 因 UNet 解冻存储梯度)
- nohup 脱离终端运行
