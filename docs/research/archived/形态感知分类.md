# 方向 C：形态感知分类增强 (Morphology-Aware Classification)

> **目标**：通过处理 bad case (形态相似类混淆) 提升分类性能，不纠结 sml 尺度权衡。诊断显示 G22→F19/F20, Y→E18 (5.4%), C 组内部混淆严重。
>
> **数据集分析支撑**：见 [dataset_overlap_analysis](../../../tmp/dataset_overlap_result.txt) — 染色体数据集的特殊性
>
> **当前代码位置**：[ldmdet/core/single_head.py](../../ldmdet/core/single_head.py) 的 cls_head

---

## 1. 数据集特性分析 (关键约束)

### 1.1 类别与数量分布

数据集类别为 1-22 号常染色体 + X + Y (共 24 类):
- 数量分布相对均衡: 2088-2232 (常染色体), X=1521, **Y=580** (最少)
- Y 类样本不足是不平衡的主要来源 (与最多类 2232 的比例 1:3.85)

### 1.2 重叠率分析 (关键约束)

| 指标 | train split | 含义 |
|------|------------|------|
| 存在任意重叠 (IoU>0) 的图 | **100%** | 每张图都有框重叠 |
| 存在显著重叠 (IoU>0.3) 的图 | 44.6% | 近半数图有明显重叠 |
| 存在高重叠 (IoU>0.5) 的图 | 9.4% | 少数图严重重叠 |
| IoU>0 的框对占比 | 2.6% | 绝大多数框不重叠 |
| 完全无重叠 (IoU<0.1) 的图 | **2.2%** | 几乎所有图都有重叠 |

**关键结论**: 染色体图像中框重叠普遍存在 (97.8% 的图有重叠)，但重叠框对占比低 (2.6%)。这意味着:
- **太强的先验特征 (如 HOG/LBP 全局特征) 可能受重叠干扰** — 用户担忧成立
- **局部形态特征 (RoI 内部) 受重叠影响较小** — 因为重叠框对仅 2.6%

### 1.3 类别共现

几乎所有类别对都在 1100+/1155 张图共现 (如 14<->17: 1135 张)。这意味着每张图都包含各类染色体，**无法做类别单独训练**。

## 2. 子方向说明

### C1: 局部形状注意力 (Local Shape Attention, 不受重叠干扰)

**思路**: 在 RoI 特征 (已提取的 7x7 区域) 上加形状注意力，而非全图先验。RoI 内部是单条染色体，不受重叠干扰。

**方案**:
```python
class ShapeAttention(nn.Module):
    def __init__(self, channels):
        self.h_branch = nn.Conv2d(channels, channels//4, (7,1))  # 水平方向 (臂长)
        self.v_branch = nn.Conv2d(channels, channels//4, (1,7))  # 垂直方向 (着丝粒)
        self.fuse = nn.Conv2d(channels//2, channels, 1)
    def forward(self, x):  # x: (N, C, 7, 7) RoI 特征
        h = self.h_branch(x)  # 捕获水平形态
        v = self.v_branch(x)  # 捕获垂直形态
        return self.fuse(cat([h, v])) + x  # 残差
```

**为什么不受重叠干扰**: RoIAlign 已将每条染色体提取到独立 7x7 特征图，重叠框的 RoI 内部仍是单条染色体特征。

**收益**: 显式编码染色体臂长比、着丝粒位置等形态信息。

### C2: 对比学习辅助损失 (Contrastive Aux Loss)

**思路**: 拉大形态相似类 (G-F, Y-E18) 的特征距离，提升判别力。

**方案**:
- 在 RoI 特征上加投影头，输出 128 维嵌入
- 对每个 batch，构造正对 (同类不同实例) 和负对 (形态相似类)
- 辅助损失: $\mathcal{L}_{contrast} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_k \exp(\text{sim}(z_i, z_k)/\tau)}$

**对比对构建** (从数据集分析):
- 困难负对 (形态相似): G21-G22, F19-F20, Y-E18, C6-C7 (从诊断 confusion matrix 提取)
- 正对: 同类不同图实例

**大小尺寸平衡**:
- 在嵌入空间用归一化特征 (cosine similarity)，消除尺寸影响
- 或按尺寸分桶采样 (小框-小框对比, 大框-大框对比)

### C3: 困难类别重加权 (已有 2b 实验)

**思路**: 对形态相似类加大分类损失权重。

**方案**: 2b 实验的 focal_gamma_3 / high_cls_weight 即验证此思路，等待结果。

## 3. 推荐组合配置 (C1 + C2)

**子方向互相抵消评估**:
- C1 局部形状注意力 → 增强形态特征
- C2 对比学习 → 拉大相似类距离
- 二者**互补** (C1 提供更好特征，C2 用这些特征做对比)，可组合

**组合配置**:

| 配置项 | baseline | C1+C2 组合 |
|--------|----------|-----------|
| cls_head 前置 | 直接 cls_head | ShapeAttention + 投影头 (C1+C2) |
| 损失 | FocalLoss | FocalLoss + ContrastiveLoss (w=0.1) |
| 困难负对 | 无 | G-F, Y-E18 等 (C2) |

**预期**:
- G22/G21/Y 类 AP +0.02 ~ +0.05
- mAP50 +0.01 ~ +0.02
- 若困难类 AP 提升 > 0.03，方向 C 确认可行

## 4. 重叠情况下的可行性论证

### 用户担忧: 太强的先验特征能否处理重叠?

**回答**: C1 设计避免了此问题:
1. **RoI 内部无重叠**: RoIAlign 将每条染色体提取到独立 7x7 特征，重叠框的 RoI 内部仍是单条染色体
2. **局部而非全局特征**: C1 在 RoI 上操作，不是全图先验 (如 HOG 全图会受重叠干扰)
3. **数据支撑**: 重叠框对仅 2.6%，即使先验特征偶尔受干扰，影响有限

**C2 对比学习也适用**:
- 对比对从 RoI 特征构建，不依赖全图
- 重叠框的 RoI 特征仍是单条染色体，对比有效

## 6. 风险与可行性

| 风险 | 评估 |
|------|------|
| C1 形状注意力受重叠干扰 | **低** (RoI 内部无重叠, 数据支撑) |
| C2 对比对构建复杂 | 中 (需从 confusion matrix 提取困难对) |
| C2 大小尺寸对比不平衡 | 用归一化特征或分桶采样解决 |
| 对比损失权重需调参 | w=0.1 起步，根据训练稳定性调整 |

**结论**：方向 C 可行，C1+C2 组合在 RoI 层面操作避免重叠干扰。与方向 B (解耦分支) 互补 — B 改进结构，C 改进特征和损失。
