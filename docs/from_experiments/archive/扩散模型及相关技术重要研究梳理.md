# 扩散模型及相关技术重要研究梳理

---

## 一、近三年（2022–2024）最重要的 5 项研究

### 1. Latent Diffusion Models（LDM / Stable Diffusion）

> Rombach et al., *"High-Resolution Image Synthesis with Latent Diffusion Models"*, **CVPR 2022**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 将扩散过程从像素空间转移到 VAE 潜在空间，计算开销降低数十倍 |
| **深远影响** | 奠定了 Stable Diffusion 系列的架构基础；开源策略引爆了整个 AIGC 社区，催生了 LoRA、ControlNet 等庞大生态 |
| **关键洞察** | 高维像素空间中大量计算花在"感知无关"的细节上，潜在空间才是语义建模的高效场所 |

---

### 2. Scalable Diffusion Models with Transformers（DiT）

> Peebles & Xie, **ICCV 2023**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 用 Vision Transformer 替代 U-Net 作为扩散模型的去噪骨干网络 |
| **深远影响** | 验证了 **Scaling Law** 在扩散模型中成立（模型越大、FID 越低）；直接启发了后续 Sora、SD3、FLUX 等里程碑工作 |
| **关键洞察** | U-Net 并非必需，Transformer 的可扩展性才是通往更强生成能力的关键 |

---

### 3. ControlNet

> Zhang & Agrawala, *"Adding Conditional Control to Text-to-Image Diffusion Models"*, **ICCV 2023**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 通过"锁定原模型 + 可训练副本"的 zero-convolution 架构，为预训练扩散模型注入边缘图、深度图、姿态等空间条件 |
| **深远影响** | 使扩散模型从"不可控的艺术玩具"变为"精准可控的生产工具"，极大推动了工业落地 |
| **关键洞察** | 不需要重新训练基础模型，即可获得细粒度的空间控制能力 |

---

### 4. Flow Matching for Generative Modeling

> Lipman et al., **ICLR 2023**；以及 Liu et al. 的 **Rectified Flow** 系列
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 用最优传输思想构建噪声→数据的**直线路径**，提供比传统 DDPM/Score SDE 更简洁的训练目标 |
| **深远影响** | 成为新一代生成范式——SD3、FLUX、Stable Audio 等均采用 Rectified Flow；在理论上统一了扩散模型与连续归一化流 |
| **关键洞察** | 更直的传输路径 → 更少的采样步数 → 更快的推理 |

---

### 5. Consistency Models

> Song et al., **ICML 2023**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 提出学习"同一轨迹上任意点映射到起点"的自洽函数，实现 **单步或极少步生成** |
| **深远影响** | 从根本上挑战了"扩散模型必须多步迭代"的范式，开辟了快速生成的新路线 |
| **关键洞察** | 不需要依赖 ODE 求解器的逐步去噪，直接学习轨迹的全局映射 |

---

## 二、最近一年（2024）最重要的 5 项研究

### 1. Sora —— Video Generation as World Simulation

> OpenAI, **2024.02**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 基于 **Spacetime DiT + Patch 化视频 token**，首次展示分钟级、高保真、物理一致的长视频生成 |
| **里程碑意义** | 将扩散模型从图像推向 **"世界模拟器"** 的概念高度，重新定义了视频生成的上限 |

---

### 2. Scaling Rectified Flow Transformers（SD3 / FLUX）

> Esser et al., *"Scaling Rectified Flow Transformers for High-Resolution Image Synthesis"*, **2024**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 提出 **MM-DiT（多模态双流 DiT）** 架构，将文本与图像 token 在同一 Transformer 中进行双向注意力交互；结合 Rectified Flow 训练 |
| **里程碑意义** | SD3 和 FLUX.1 成为开源图像生成的新 SOTA；证明了 Flow + Transformer 路线的优越性 |

---

### 3. Improved Techniques for Training Consistency Models（iCT）

> Song & Dhariwal, **ICML 2024**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 通过改进的 noise schedule、伪 Huber 损失、课程学习等技巧，将 Consistency Model 的生成质量提升到接近甚至追平多步扩散模型 |
| **里程碑意义** | 证明了单/少步生成在质量上不再需要妥协，极大增强了该路线的实用性 |

---

### 4. 蒸馏加速家族：SDXL-Lightning / Hyper-SD / DMD2

> 分别来自 ByteDance、ByteDance、MIT 等，**2024**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | **对抗蒸馏 + 分数蒸馏 + 渐进蒸馏** 等多种范式的组合，使 SDXL/SD3 级模型实现 **1–4 步高质量生成** |
| **里程碑意义** | 将实时交互式图像生成变为现实（单张图 <100ms on consumer GPU） |

---

### 5. CogVideoX / Open-Sora 系列

> 智谱 AI / HPC-AI Tech 等，**2024**
> 

| 维度 | 说明 |
| --- | --- |
| **核心贡献** | 开源的 DiT-based 视频生成模型，支持数秒至十余秒的文本到视频生成，提供了完整训练流程 |
| **里程碑意义** | 填补了 Sora 非开源带来的空白，推动视频生成的民主化研究 |

| 代表工作 | Sora, Genie (DeepMind), GameNGen, UniSim |
| --- | --- |

| **关键挑战** | 长时一致性、物理规律遵循、可控交互 |

| --- | --- |
| **潜力** | 扩散模型正在成为**科学发现的通用生成引擎**——药物设计、材料科学、气象预报等领域均出现突破 |
| **关键挑战** | 物理约束的严格满足、可解释性 |

---

### 3. 🎭 统一多模态生成架构

| 代表工作 | Transfusion (Meta)、Show-o、Chameleon、OmniGen |
| --- | --- |
| **潜力** | 将自回归（离散 token）与扩散（连续信号）统一到**单一 Transformer** 中，实现文本/图像/音频/视频的任意模态生成与理解 |
| **关键挑战** | 不同模态的最优建模方式不同，统一后如何避免性能折损 |

---

### 4. 🏗️ 3D / 4D 资产生成

| **关键挑战** | 几何精度、纹理质量、与现有渲染管线的兼容 |

---

### 5. ⚡ 扩散模型的极限加速与端侧部署

| 代表工作 | Consistency Distillation 系列、SDXL-Lightning、MobileDiffusion、Snapdragon on-device diffusion |

| **关键挑战** | 单步质量与多步质量的差距、低精度下的稳定性 |

## 总结时间线图

```
2022 ──────────────────── 2023 ──────────────────── 2024 ──────────── 2025
  │                         │                         │
  ├─ LDM/Stable Diffusion   ├─ DiT                    ├─ Sora / 视频生成
  ├─ DALL·E 2 / Imagen      ├─ ControlNet             ├─ SD3 / FLUX (Rectified Flow + MM-DiT)
  │                         ├─ Flow Matching           ├─ iCT (改进 Consistency Models)
  │                         ├─ Consistency Models      ├─ 蒸馏加速 (Lightning/Hyper-SD)
  │                         ├─ DreamBooth / LoRA       ├─ AlphaFold3 diffusion
  │                         │                         ├─ Transfusion (统一多模态)
  │                         │                         ├─ 3D Gaussian + Diffusion
  │                         │                         └─ On-device Diffusion
  范式奠基                    架构革新 + 可控性           规模化 + 多模态 + 落地
```

> **一句话趋势总结**：扩散模型正沿着 **"U-Net → Transformer → 多模态统一架构"** 的主线演进，同时在速度（Flow Matching / Consistency / 蒸馏）和应用领域（视频 → 3D → 科学计算 → 世界模拟）两个维度上快速扩展。
